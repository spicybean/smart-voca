# 스마트보카 UI 설계서

**파일 위치**: `ai-agent/claude/분석_261111_UI설계서 v1.2.md`
**작성일**: 2026-11-11
**버전**: v1.2
**설명**: PyQt6 기반 사용자 인터페이스 설계 (요구사항 명세서 v1.2, 데이터 설계서 v1.2 반영)

---

## 1. 개요

### 1.1 UI 철학
- **직관성**: 비개발자도 쉽게 사용
- **일관성**: 모든 화면에서 동일한 패턴
- **응답성**: 버튼 클릭 즉시 반응
- **최소화**: 불필요한 요소 제거
- **투명성**: 진도에 반영되는 것과 아닌 것을 화면에서 구분해 알려준다 (재풀이·보너스 안내)

### 1.2 화면 구성

스마트보카는 **탭 기반 인터페이스**로 4개 화면을 제공합니다.

1. 홈 (Home) - 대시보드
2. 퀴즈 (Quiz) - 퀴즈 풀이
3. 단어 (Word) - 단어 관리
4. 설정 (Settings) - 학습 설정

---

## 2. 화면 설계

### 2.1 메인 윈도우 (MainWindow)

**기본 정보**:
- 윈도우 크기: 1000 x 700 (고정)
- 제목: "스마트보카"
- 태스크바 아이콘: 앱 로고

**레이아웃**:
```
┌─────────────────────────────────────────┐
│ 스마트보카                      [_][□][✕] │
├─────────────────────────────────────────┤
│ [홈] [퀴즈] [단어] [설정]                │ ← 탭 바
├─────────────────────────────────────────┤
│                                         │
│          현재 탭의 내용                  │
│          (Home/Quiz/Word/Settings)      │
│                                         │
└─────────────────────────────────────────┘
```

**주요 요소**:
- 상단: 윈도우 제목 + 최소/최대/닫기 버튼
- 중단: 탭 메뉴 (4개)
- 하단: 탭별 콘텐츠

**앱 종료 시 동작**: 자동 백업 실행 (요구사항 FR-1.8). 퀴즈 세션이 진행 중이면 세션 정보를 저장한 뒤 종료한다 (FR-3.6).

### 2.2 홈 화면 (Home Tab)

**목적**: 학습 현황 대시보드

**레이아웃**:
```
┌───────────────────────────────────────────────┐
│ 📚 스마트보카 - 홈                            │
├───────────────────────────────────────────────┤
│                                               │
│ 📊 학습 현황                                  │
│ ───────────────────────────────────────────── │
│ 전체 진도율: 65%  ████████░░░░░░             │
│                                               │
│ 등록된 단어: 1,500개  |  학습 완료: 975개    │
│ 오늘 학습할 단어: 10개                        │
│                                               │
│ 🎯 분야별 진도 [▼ 펼치기]                    │
│ ───────────────────────────────────────────── │
│ • 일상: 70%  ██████░░░░                      │
│ • 비즈니스: 55%  █████░░░░░                  │
│ • 미분류: 20%  ██░░░░░░░░                    │
│                                               │
│ 🔥 최근 활동                                  │
│ ───────────────────────────────────────────── │
│ 어제 완료: 12문항                            │
│ 오늘 진행: 8/10 진행 중...                   │
│                                               │
│ [이어서 풀기] [퀴즈 시작하기] [단어 관리] [설정] │
│                                               │
└───────────────────────────────────────────────┘
```

**요소 상세**:

| 요소 | 컴포넌트 | 상세 |
|------|---------|------|
| 전체 진도율 | QProgressBar | 학습 완료(숙달) 단어 ÷ 전체 단어 × 100. 정수 표시 |
| 통계 텍스트 | QLabel | 등록 단어 수, 학습 완료 수 |
| 오늘 학습할 단어 | QLabel | 퀴즈 시작 전에는 설정값, 세션 진행 중에는 세션 문항 수 |
| 분야별 진도 | QToolButton(펼치기) + QProgressBar | 일상 / 비즈니스 / 미분류 3행 |
| 최근 활동 | QLabel | 어제 완료 문항 수, 오늘 진행 (완료 / 구성 문항) |
| 퀴즈 버튼 | QPushButton | 세션이 없으면 [퀴즈 시작하기], 세션이 있으면 [이어서 풀기]로 바뀜. 두 버튼을 동시에 보이지 않음 |
| 단어 관리 / 설정 버튼 | QPushButton | 각 탭으로 이동 |

**빈 상태**: 단어가 0개면 전체 진도율 자리에 "단어를 추가해 주세요" 안내와 [단어 관리] 버튼을 강조한다.

### 2.3 퀴즈 화면 (Quiz Tab)

#### 2.3.1 퀴즈 시작 전 화면

**레이아웃**:
```
┌──────────────────────────────────────────┐
│ 🎯 퀴즈 준비                             │
├──────────────────────────────────────────┤
│                                          │
│ 오늘의 퀴즈 정보                         │
│                                          │
│ 분야: 비즈니스                           │
│ 일일 학습량: 10개                        │
│                                          │
│ 오늘 퀴즈 구성:                          │
│ • 신규·약한 단어: 7개                    │
│ • 복습 대상: 2개                         │
│ • 자주 틀린 단어: 1개                    │
│                                          │
│ ─────────────────────────────────────── │
│                                          │
│ [퀴즈 시작하기]   [나중에]               │
│                                          │
└──────────────────────────────────────────┘
```

**조건별 안내 문구**:
- 오늘 기본 퀴즈를 이미 완료했으면: "오늘 퀴즈는 완료했습니다. 다시 풀기는 진도에 반영되지 않습니다." 를 표시하고 버튼은 [다시 풀기] [나중에]
- 등록 단어가 설정 학습량보다 적으면: "오늘 퀴즈는 N개 중 M개입니다" 표시
- 분야 단어가 4개 미만이면: "보기를 만들 단어가 부족합니다. 단어를 더 추가해 주세요" 표시하고 [퀴즈 시작하기] 비활성화
- 이어서 풀기 세션이 있으면 이 화면 대신 퀴즈 진행 화면으로 바로 이동한다 (2.3.5)

#### 2.3.2 퀴즈 진행 중 화면

**레이아웃**:
```
┌──────────────────────────────────────────────┐
│ 📝 퀴즈 진행                                 │
├──────────────────────────────────────────────┤
│                                              │
│ 진행도: 3/10  ███░░░░░░░░░░ (30%)           │
│                                              │
│ ─────────────────────────────────────────── │
│                                              │
│ 문제 3: 한→영                               │
│                                              │
│ "사과는?"                                    │
│                                              │
│ ① apple           ② banana                  │
│                                              │
│ ③ orange          ④ grape                   │
│                                              │
│ ─────────────────────────────────────────── │
│                                              │
│ ✓ 정답입니다!                                │
│ (오답이면: ✗ 오답입니다. 정답: apple 강조)    │
│                                              │
│ [다음 문제]                  [그만하기]       │
│                                              │
└──────────────────────────────────────────────┘
```

**요소 상세**:
- 진행도 바: QProgressBar (현재 문항 / 전체 문항)
- 문제 유형: QLabel (한→영 또는 영→한)
- 문제 텍스트: 크고 명확한 QLabel
- 선택지 버튼: 4개 QPushButton
  - 정상: 회색, 마우스 오버 시 밝게
  - 선택 후 (즉시 채점): 내가 고른 것이 정답이면 녹색, 오답이면 빨간색. 오답이면 정답 선택지를 녹색 테두리로 강조
  - 채점 후에는 4개 모두 비활성화
- 결과 메시지: QLabel (✓ 정답 / ✗ 오답)
- [다음 문제] 버튼: 채점 전에는 비활성화. 마지막 문항에서는 [완료]로 바뀜
- [그만하기] 버튼: 세션을 저장하고 홈으로 이동. 나중에 "이어서 풀기"로 재개 (FR-3.6)

**재풀이 표시**: 재풀이 세션이면 상단에 "다시 풀기 중 · 진도에 반영되지 않습니다" 배지를 표시한다.

#### 2.3.5 이어서 풀기 화면 (신규, FR-3.6)

**진입**: 홈 화면의 [이어서 풀기] 버튼 또는 퀴즈 탭을 열 때 저장된 세션이 있으면 자동 표시.

**레이아웃**:
```
┌──────────────────────────────────────────┐
│ 📝 이어서 풀기                           │
├──────────────────────────────────────────┤
│                                          │
│ 지난번 퀴즈가 6/10 문항에서 멈췄습니다.  │
│ 세션 날짜: 2026-10-28                    │
│                                          │
│ [이어서 풀기]   [세션 버리기]            │
│                                          │
└──────────────────────────────────────────┘
```

- [이어서 풀기]: 2.3.2 화면으로 이동. 저장된 문항과 보기를 그대로 사용한다.
- [세션 버리기]: 확인 대화상자 후 세션 정보를 삭제한다. 이미 저장된 답변 기록은 지우지 않는다.
- 세션에 있던 단어가 삭제되었으면 해당 문항은 건너뛴다. 건너뛴 사실은 표시하지 않는다.

### 2.4 단어 관리 화면 (Word Tab)

**레이아웃**:
```
┌──────────────────────────────────────────────────────┐
│ 📖 단어 관리                                         │
├──────────────────────────────────────────────────────┤
│                                                      │
│ [검색] _____________ [분야: 전체▼] [정렬: 단어순▼] [+ 추가] │
│                                                      │
│ 단어     뜻      상태     습득도  마지막복습  정답/시도  │
│ ──────────────────────────────────────────────────── │
│ apple    사과    숙달     95%     2026-10-20  19/20  [✕] │
│ banana   바나나  학습중   70%     2026-10-21  7/10   [✕] │
│ cat      고양이  복습필요 60%     2026-10-19  6/10   [✕] │
│ dog      개      미학습   -       -           0/0    [✕] │
│ ...                                                  │
│ ──────────────────────────────────────────────────── │
│ 페이지: 1/75 [◄] [►]                                 │
│                                                      │
└──────────────────────────────────────────────────────┘
```

**요소 상세**:

| 요소 | 컴포넌트 | 상세 |
|------|---------|------|
| 검색 | QLineEdit | 단어 또는 뜻 검색 |
| 분야 필터 | QComboBox | 전체 / 일상 / 비즈니스 / 미분류 |
| 정렬 | QComboBox | 단어순 / 상태순 / 진도순 (FR-1.2) |
| 추가 | QPushButton | 새 단어 추가 팝업 (2.4.1) |
| 테이블 | QTableWidget | 단어 목록, 20행/페이지 |
| 페이지 | QLabel + QPushButton | 이전/다음 페이지 |

**테이블 열** (요구사항 FR-1.2, FR-4.2 기준):
- 단어 (영어)
- 뜻 (한글)
- 상태 (미학습 / 학습중 / 복습필요 / 숙달, 색상 배지 4.4 참조)
- 습득도 (%), 시도 0이면 `-`
- 마지막복습 (날짜), 없으면 `-`
- 정답/시도 (예: "7/10")
- 삭제 버튼 (✕)

v1.0의 체크박스 열은 요구사항에 일괄 작업이 없어서 제거했습니다.

**정렬 규칙**: 습득도가 `-`인 행(시도 0)은 진도순·습득도 정렬에서 맨 뒤에 둔다.

**행 동작**:
- 행 클릭 → 단어 상세 보기 (2.4.2)
- ✕ 클릭 → 삭제 확인 대화상자 (2.6)

#### 2.4.1 단어 추가 / 수정 팝업

추가와 수정은 같은 폼을 쓴다. 수정은 기존 값을 채워서 연다.

**레이아웃**:
```
┌──────────────────────────────┐
│ 새 단어 추가 (수정 시: 단어 수정) │
├──────────────────────────────┤
│                              │
│ 영어 (필수):  ________       │
│ 한글 (필수):  ________       │
│ 분야 (선택):  [미분류▼]     │
│ 난이도 (선택): [1▼]         │
│                              │
│ [저장]  [취소]               │
│                              │
└──────────────────────────────┘
```

- 분야 기본값: 미분류, 난이도 기본값: 1
- 저장 시 영어 중복 검사 (앞뒤 공백 제거, 대소문자 무시). 중복이면 경고하고 저장하지 않음 (FR-1.7-A)
- 추가 저장 후 예문 자동 조회를 시작한다. 조회 결과는 상세 보기에서 확인한다 (FR-1.5)
- 수정 저장 시 학습 기록(Progress)은 유지된다
- [취소]: 변경 없이 닫는다

#### 2.4.2 단어 상세 보기

**레이아웃**:
```
┌──────────────────────────────────────┐
│ apple - 단어 상세                    │
├──────────────────────────────────────┤
│                                      │
│ 영어: apple                          │
│ 한글: 사과                           │
│ 분야: 일상                           │
│ 난이도: 1                            │
│                                      │
│ ─────────────────────────────────── │
│ 예문:                  [예문 조회]   │
│ ─────────────────────────────────── │
│                                      │
│ 1. I eat an apple every day.         │
│    [출처: API]                       │
│                                      │
│ 2. New York is called the Big Apple. │
│    [출처: API]                       │
│                                      │
│ 3. 사과를 깎고 있습니다.             │
│    [출처: 사용자] [✕]                │
│                                      │
│ 예문이 부족합니다. 직접 추가해 보세요 │ ← 3개 미만일 때만
│ 새 예문: __________  [추가]          │
│                                      │
│ ─────────────────────────────────── │
│ 통계:                                │
│ 정답 19 | 오답 1 | 연속 정답 5        │
│ 정답률: 95%                          │
│ 다음 복습: 2026-10-25                │
│                                      │
│ [수정]  [삭제]  [닫기]               │
│                                      │
└──────────────────────────────────────┘
```

**요소 상세**:
- [예문 조회]: 캐시를 무시하고 API를 다시 호출한다. 기존 예문과 같은 문장은 추가하지 않는다 (FR-1.5)
- 예문 출처 표시: API / 사용자
- ✕: 사용자 예문만 삭제 가능 (FR-1.6)
- 새 예문 입력: 공백만 입력하면 [추가]가 비활성화된다 (FR-1.6)
- 통계: 정답/오답 횟수, 연속 정답, 정답률 (시도 0이면 `-`), 다음 복습 날짜 (FR-4.2)
- 예문 조회 실패 시 2차 폴백(사용자 입력 유도), 3차 "나중에 다시 시도하세요" 안내 (FR-1.5)
- [수정]: 2.4.1 팝업을 수정 모드로 연다
- [삭제]: 삭제 확인 대화상자 (2.6)

## 3. 사용자 플로우 (User Flow)

### 3.1 첫 실행 플로우

```
앱 시작
  ↓
DB 확인
  ├─ DB 없음 → 자동 초기화 (init_db.py)
  ├─ DB 있음, 정상 → 계속
  └─ DB 있음, 손상 → 데이터베이스 오류 대화상자 (2.6)
  ↓
메인 윈도우 표시
  ↓
홈 화면 표시 (진도율 0%)
  ↓
[퀴즈 시작하기] 또는 [설정] 클릭 가능
```

### 3.2 일반적인 학습 플로우

```
홈 화면
  ↓
[퀴즈 시작하기] 클릭 (세션이 있으면 [이어서 풀기])
  ↓
퀴즈 준비 화면 (2.3.1)
  ↓
[퀴즈 시작하기] 클릭 → 세션 생성
  ↓
문제 1~N 풀이 (한→영, 영→한 혼합)
  ├─ 정답 → ✓ 표시, 기록 저장, 진도 반영
  └─ 오답 → ✗ 표시 + 정답 강조, 기록 저장, 진도 반영
  ↓
[다음 문제] 반복 (언제든 [그만하기] → 세션 저장 후 홈)
  ↓
N개 완료
  ↓
보너스 대상 있음?
  ├─ 없음 → 결과 화면
  └─ 있음 → 보너스 화면 (2.3.3)
       ├─ [보너스 도전하기] → 보너스 문제 풀이 (진도 미반영)
       └─ [건너뛰기] → 결과 화면
  ↓
결과 화면 (정답률, 진도 표시)
  ↓
[홈으로] 또는 [다시 풀기] 클릭
  ↓
홈 화면 (진도율 업데이트)
```

### 3.3 퀴즈 재개 플로우 (신규)

```
앱 실행 또는 퀴즈 탭 진입
  ↓
저장된 세션 있음?
  ├─ 없음 → 일반 플로우
  └─ 있음 → 이어서 풀기 화면 (2.3.5)
       ├─ [이어서 풀기] → 저장된 위치의 문항부터 진행
       └─ [세션 버리기] → 확인 → 세션 삭제 → 홈
```

### 3.4 재풀이 플로우 (신규)

```
결과 화면 → [다시 풀기] 클릭
  ↓
준비 화면 → 안내 "진도에 반영되지 않습니다" 확인
  ↓
[퀴즈 시작하기] → 재풀이 세션 (배지 표시)
  ↓
답변은 기록만 저장, 진도(Progress)는 변하지 않음
```

### 3.5 단어 관리 플로우

```
단어 탭 클릭
  ↓
단어 목록 표시 (20개/페이지, 정렬·필터 적용)
  ↓
┌─ [검색] 입력 → 결과 필터링
│
├─ [분야] / [정렬] 선택 → 목록 갱신
│
├─ [+ 추가] 클릭 → 추가 팝업 (2.4.1)
│   ├─ 영어/한글/분야/난이도 입력
│   ├─ [저장] → 중복 검사 → 단어 추가 → 예문 자동 조회
│   └─ [취소] → 닫기
│
├─ 단어 행 클릭 → 상세 보기 (2.4.2)
│   ├─ 예문 표시, [예문 조회] (캐시 무시 재조회)
│   ├─ 사용자 예문 추가 / 삭제
│   ├─ [수정] → 수정 팝업 (2.4.1, 학습 기록 유지)
│   ├─ [삭제] → 삭제 확인 (2.6)
│   └─ [닫기]
│
└─ [✕] 버튼 클릭 → 삭제 확인 (2.6)
    └─ [삭제] → 단어 삭제 (CASCADE)
```

### 3.6 백업 및 복구 플로우 (신규)

```
설정 탭 → [백업 만들기]
  ↓
저장 위치 선택 → manual_*.db 생성 → 완료 메시지

설정 탭 → [백업에서 복구]
  ↓
백업 파일 선택 → 검증
  ├─ 실패 → 복구 실패 대화상자 (2.6)
  └─ 성공 → 복구 확인 (2.6)
       ├─ [취소] → 종료
       └─ [복구] → pre_restore_*.db 생성 → 복원 → 홈 화면 갱신
```

## 5. 반응형 요소

### 5.1 버튼 상태

```
기본 상태: 회색, 텍스트 검은색
마우스 오버: 밝은 회색, 커서 변경
클릭: 더 어두운 색
비활성화: 회색 + 50% 투명도
```

**비활성화 규칙**:
- 퀴즈 [다음 문제]: 채점 전에는 비활성화
- 퀴즈 선택지: 채점 후 4개 모두 비활성화
- 퀴즈 [퀴즈 시작하기]: 분야 단어가 4개 미만이면 비활성화
- 설정 [저장]: 변경이 없으면 비활성화
- 단어 추가 [저장]: 영어 또는 한글이 비어 있으면 비활성화
- 예문 [추가]: 공백만 입력하면 비활성화
- 홈 [이어서 풀기]: 세션이 없으면 표시하지 않음

### 5.2 입력 필드

```
기본: 흰색 배경, 검은색 테두리
포커스: 파란색 테두리, 2px 두께
오류: 빨간색 테두리 + 아래에 오류 문구 (예: "이미 등록된 단어입니다")
```

### 5.3 진행 바

```
배경: 연한 회색
진행: Primary 색상 (초록색)
텍스트: 검은색 (중앙)
높이: 20px
```
