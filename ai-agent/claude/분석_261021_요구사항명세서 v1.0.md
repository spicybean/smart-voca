## 1. 개요

본 문서는 스마트보카의 상세한 기능 요구사항과 비기능 요구사항을 명시합니다.

### 1.1 용어 정의

| 용어 | 설명 |
|------|------|
| **학생** | 스마트보카 앱을 사용하는 사용자 |
| **단어** | 학습 대상이 되는 영문 단어 |
| **진도(Progress)** | 학생이 각 단어에 대해 이룬 학습 성과 |
| **복습 예정일** | 간격 반복 알고리즘에 의해 정해진 다음 복습 날짜 |
| **퀴즈** | 학생이 풀어야 할 문제 (4지선다형) |
| **보너스 문제** | 기본 퀴즈 완료 후 자동 추천되는 추가 문제 |

## 2. 기능 요구사항 (FRD: Functional Requirements)

### 2.1 단어 관리 기능

#### FR-1.1: 초기 데이터 로드
**목적**: 앱 첫 실행 시 1,500개 단어를 DB에 자동 로드

**상세 요구사항**:
- [ ] 앱 첫 실행 시 DB 존재 여부 확인
- [ ] DB 없으면 init_db.py 자동 실행
- [ ] `data/words_common.csv` (일상 1,000개) 로드
- [ ] `data/words_business.csv` (비즈니스 500개) 로드
- [ ] 각 단어의 Progress 초기화 (상태: 미학습, correct_count: 0)
- [ ] 로드 완료 메시지 표시 또는 자동으로 진행

**성공 기준**:
- DB 파일 생성됨
- Word 테이블에 1,500개 레코드
- Progress 테이블에 1,500개 레코드 (모두 미학습)

---

#### FR-1.2: 단어 조회
**목적**: 학생이 등록된 단어 목록을 확인

**화면**: 단어 관리 탭

**상세 요구사항**:
- [ ] 테이블 형식으로 단어 목록 표시
  - 열: 단어(영어) | 뜻(한글) | 상태 | 습득도(%) | 마지막복습 | 정답횟수
- [ ] 페이지네이션 (1페이지당 20개 표시)
- [ ] 분야별 필터링 (선택사항)
- [ ] 키워드 검색 (단어 또는 뜻)
- [ ] 정렬 기능 (단어순, 상태순, 진도순)

**성공 기준**:
- 20개씩 정상 표시
- 검색 결과 정확함
- 필터링 작동

---

#### FR-1.3: 단어 추가
**목적**: 학생이 새로운 단어를 등록

**화면**: 단어 관리 탭 - 추가 버튼

**상세 요구사항**:
- [ ] 팝업 또는 새 화면으로 입력 폼 표시
  - 입력 필드: 영어(필수), 한글(필수), 분야(선택), 난이도(1-5, 선택)
- [ ] 영어 중복 검사 (같은 단어 이미 존재 시 경고)
- [ ] 저장 시 Word 테이블에 추가
- [ ] 자동으로 Progress 생성 (미학습 상태)
- [ ] 성공 메시지 표시

**성공 기준**:
- 단어 저장 완료
- Progress 자동 생성
- 목록에 즉시 반영

---

#### FR-1.4: 단어 삭제
**목적**: 학생이 불필요한 단어 제거

**화면**: 단어 관리 탭

**상세 요구사항**:
- [ ] 단어 옆에 삭제 버튼
- [ ] 클릭 시 확인 대화상자 ("정말 삭제하시겠어요?")
- [ ] 확인 시 Word 레코드 삭제
- [ ] 관련 Example, Progress, Quiz 레코드도 삭제 (CASCADE)
- [ ] 성공 메시지 표시

**성공 기준**:
- DB에서 단어 제거됨
- 관련 데이터도 함께 제거됨
- UI에서 즉시 반영

---

#### FR-1.5: 사전 API를 통한 예문 조회
**목적**: 단어별 예문을 자동으로 조회해서 표시

**트리거**: 새 단어 추가 시 또는 학생이 "예문 조회" 버튼 클릭

**상세 요구사항**:
- [ ] WordsAPI/Cambridge Dictionary API 호출
- [ ] API 응답에서 예문 3~5개 추출
- [ ] Example 테이블에 저장 (source: "api")
- [ ] 화면에 예문 표시
- [ ] API 실패 시 폴백:
  - 1차: 캐시 확인
  - 2차: 사용자 입력 예문 사용
  - 3차: "나중에 다시 시도하세요" 메시지

**성공 기준**:
- 예문 3개 이상 표시됨
- API 오류 시에도 앱 정상 작동

---

#### FR-1.6: 사용자 예문 추가
**목적**: 학생이 직접 예문을 입력해서 추가

**화면**: 단어 상세 보기

**상세 요구사항**:
- [ ] 예문 입력 필드
- [ ] 추가 버튼
- [ ] 입력된 예문을 Example 테이블에 저장 (source: "user")
- [ ] 목록에 즉시 추가됨

**성공 기준**:
- 사용자 예문 저장 완료
- 목록에 표시됨

### 2.2 학습 설정 기능

#### FR-2.1: 학습 분야 선택
**목적**: 학생이 학습할 분야를 선택

**화면**: 설정 탭

**상세 요구사항**:
- [ ] 선택 옵션: 일상 / 비즈니스 / 선택안함(전체)
- [ ] 선택 시 Settings 테이블에 저장
- [ ] 저장 즉시 적용 (홈 화면에 반영)

**성공 기준**:
- 선택한 분야가 저장됨
- 퀴즈에 즉시 반영 (다음 퀴즈 세션부터)

---

#### FR-2.2: 일일 학습량 설정
**목적**: 학생이 하루에 학습할 단어 개수를 결정

**화면**: 설정 탭

**상세 요구사항**:
- [ ] 선택 옵션: 5개 / 10개 / 15개 / 커스텀
- [ ] 커스텀 선택 시 입력 필드 표시
- [ ] 1 ~ 50 범위 입력 가능
- [ ] 설정 저장 → Settings 테이블 업데이트
- [ ] 저장 즉시 적용

**성공 기준**:
- 선택값 저장됨
- 다음 퀴즈에 반영 (예: 10개 선택 → 10개 문제 제시)

---

### 2.3 퀴즈 기능

#### FR-3.1: 오늘의 퀴즈 구성
**목적**: 간격 반복 알고리즘에 따라 오늘 풀 퀴즈를 자동 생성

**트리거**: 학생이 "퀴즈 시작" 버튼 클릭

**상세 요구사항**:
- [ ] 설정된 일일 학습량(N개) 확인
- [ ] 다음 비율로 단어 선정:
  - 새 단어 또는 약한 단어(correct_rate < 70%): 50~70%
  - 복습 예정 단어(next_review_date = 오늘): 20~30%
  - 자주 틀린 단어(correct_rate < 60% AND 7일 이상 미복습): 10~20%
- [ ] 선정된 단어들로 퀴즈 목록 생성
- [ ] 4지선다형 보기 생성 (혼합 방식)
  - v1.0: 같은 카테고리, 난이도 ±1 범위
  - v1.1 이후: 학생이 자주 틀린 단어 우선

**성공 기준**:
- N개의 문제가 생성됨
- 비율이 대략 맞음 (오차 범위 ±5%)
- 4지선다형 보기가 정확함

---

#### FR-3.2: 4지선다형 양방향 퀴즈 출제
**목적**: 퀴즈를 한→영, 영→한 두 방향으로 출제

**퀴즈 화면**

**상세 요구사항**:
- [ ] 문제 유형 50:50 비율
  - 한글→영어: "사과는?" → 4개 선택지
  - 영어→한글: "apple은?" → 4개 선택지
- [ ] 각 문제마다:
  - 문제 텍스트 표시
  - 4개 선택지 버튼 (비활성화 방지)
  - 정답 선택하면 즉시 채점
  - 결과 표시 (✓ 정답 / ✗ 오답)
  - [다음 문제] 또는 [완료] 버튼

**성공 기준**:
- 한→영, 영→한 모두 출제됨
- 비율 정확함
- 채점 정상 작동

---

#### FR-3.3: 퀴즈 채점 및 기록
**목적**: 학생의 정답/오답을 기록하고 진도 업데이트

**트리거**: 학생이 정답 선택

**상세 요구사항**:
- [ ] Quiz 테이블에 기록:
  - word_id, quiz_type(한→영/영→한), is_correct(true/false), is_bonus(true/false), created_date
- [ ] Progress 테이블 업데이트:
  - 정답: correct_count +1, last_reviewed_date = 오늘
  - 오답: wrong_count +1
  - correct_rate = correct_count / (correct_count + wrong_count) * 100
  - 상태 업데이트 (미학습 → 학습중 → 복습필요 등)
  - next_review_date 계산 (간격 반복 알고리즘)
- [ ] 화면에 결과 표시

**성공 기준**:
- 데이터 정확하게 저장됨
- 진도율 정확하게 계산됨

---

#### FR-3.4: 보너스 문제 제시
**목적**: 기본 퀴즈 완료 후 약한 단어 집중 공략

**트리거**: 기본 퀴즈 N개 완료

**상세 요구사항**:
- [ ] 보너스 문제 자동 선정:
  - 조건: correct_rate < 60% AND last_reviewed_date >= 7일 전
  - 개수: 3~5개 (조건 만족 단어 수에 따라 동적)
  - 우선순위: 정답률 낮은순 → 복습이 오래된순
- [ ] 화면에 "[보너스 도전하기] / [건너뛰기]" 버튼 표시
- [ ] 도전 선택 시 보너스 퀴즈 진행
- [ ] 건너뛰기 선택 시 완료 화면으로 이동
- [ ] 보너스 점수 기록 (진도에 크게 영향 없음)

**성공 기준**:
- 보너스 문제 정확하게 선정됨
- 선택사항 정상 작동

---

#### FR-3.5: 퀴즈 완료 및 결과 화면
**목적**: 퀴즈 완료 후 결과 표시

**결과 화면**

**상세 요구사항**:
- [ ] 결과 표시:
  - 정답 개수 / 전체 개수
  - 정답률 (%)
  - 오늘 진도 (예: "975/1,500")
- [ ] 액션 버튼:
  - [다시 풀기]: 오늘 퀴즈 재진행
  - [단어 관리]: 단어 탭으로 이동
  - [홈으로]: 홈 화면으로 이동

**성공 기준**:
- 결과 정확하게 표시됨
- 버튼 정상 작동

---

### 2.4 학습 진도 추적 기능

#### FR-4.1: 홈 화면 대시보드 표시
**목적**: 학생이 학습 현황을 한눈에 파악

**화면**: 홈 탭 (기본 탭)

**상세 요구사항**:
- [ ] 학습 현황 표시:
  - 전체 진도율 (%) 및 진행 바
  - 등록된 전체 단어: X개
  - 학습 완료 단어: Y개
  - 오늘 학습할 단어: Z개
- [ ] 분야별 진도 (토글 가능):
  - 각 분야의 진도율 (%)
  - 진행 바
- [ ] 최근 활동:
  - 어제 완료 개수
  - 오늘 진행 상황 (N/M)
- [ ] 빠른 액션:
  - [퀴즈 시작하기] 버튼
  - [단어 관리] 버튼
  - [설정] 버튼

**성공 기준**:
- 모든 수치가 정확함
- 진행 바가 시각적으로 표시됨
- 버튼 정상 작동

---

#### FR-4.2: 단어별 상세 진도 정보
**목적**: 각 단어의 학습 상태를 자세히 확인

**화면**: 단어 관리 탭

**상세 요구사항**:
- [ ] 테이블 열:
  - 단어 (영어)
  - 상태 (미학습/학습중/복습필요/숙달)
  - 습득도 (%) - 정답률
  - 마지막 복습일
  - 정답/시도 (예: "7/10")
- [ ] 행을 클릭하면 상세 보기:
  - 예문들 표시
  - 통계 (정답 횟수, 오답 횟수, 복습 일정 등)
  - 수정/삭제 버튼

**성공 기준**:
- 모든 정보 정확하게 표시됨
- 상세 보기 정상 작동

## 3. 비기능 요구사항 (NFR: Non-Functional Requirements)

|----------|------|------|

## 5. 사용 사례 (Use Cases)

### 5.1 첫 실행 시나리오

```
1. 앱 실행
2. DB 없음 → 자동 초기화
3. 1,500개 단어 로드
4. 설정 화면 표시
5. 분야 선택 (일상/비즈니스)
6. 일일 학습량 선택 (5/10/15)
7. 설정 저장
8. 홈 화면 표시 (진도율 0%)
9. 학생이 "퀴즈 시작" 클릭
10. 첫 퀴즈 세션 시작
```

---

### 5.2 일반적인 학습 흐름

```
1. 홈 화면에서 "퀴즈 시작" 클릭
2. 오늘의 10개 문제 생성
   - 새 단어 5개
   - 복습 대상 3개
   - 자주 틀린 단어 2개
3. 퀴즈 풀이 (한→영 5개, 영→한 5개)
4. 각 문제마다 정답/오답 기록
5. 10개 완료
6. 보너스 문제 제시 (3개)
7. 결과 화면 표시
8. 홈 화면으로 돌아감
9. 진도율 업데이트 됨
```

## 6. 비즈니스 규칙

| 규칙 | 설명 |
|------|------|
| **간격 반복** | 정답/오답에 따라 next_review_date 자동 계산 |
| **상태 전이** | 정답률과 정답 횟수에 따라 상태 자동 변경 |
| **보너스 조건** | correct_rate < 60% AND last_reviewed >= 7일 모두 만족 |
| **카테고리 최소값** | 새 카테고리 추가 시 최소 50개 단어 필요 |
| **중복 방지** | 같은 영어 단어는 중복 추가 불가 |
