## 2026-11-11 — UI/UX 개편 (vocabulary.com 참고)

**요청**: 화면이 보기 좋지 않고 UX가 불편하니 vocabulary.com을 바탕으로 UI/UX 변경

**확인한 것**
- 스크린샷으로 현재 화면을 확인했다. 기본 Qt 스타일이라 밋밋했고, 상단 탭과 텍스트 위주 홈 화면이 어수선했다.
- vocabulary.com 홈페이지를 확인했다. 밝은 배경, 단순한 메뉴, 주요 행동 하나 강조 구성을 참고했다. 학습 화면(카드, 퀴즈 피드백)의 세부 모습은 공개 자료에서 확인되지 않아 임의로 정하지 않았다.

**사용자 결정**
- 전체 분위기: 밝은 흰 배경 + 파란 포인트
- 메뉴: 왼쪽 사이드바
- 퀴즈: 큰 카드 한 장

**처리 (단계별 커밋)**
1. `cbf037a` 스타일과 사이드바: 흰 배경, 파란 주색(#1976D2), 카드·버튼·진도 막대 QSS. 상단 탭 → 왼쪽 사이드바 + 화면 전환
2. `0e3694b` 퀴즈 화면: 문제를 카드 가운데 크게, 보기는 카드 안 큰 버튼, 정답 초록·오답 빨강, 진행 막대 얇게
3. `fca7bf8` 홈 화면: 전체 진도율·오늘 목표 카드, 분야별 진도·최근 활동 카드, 주요 버튼 하나 강조
4. `e95d250` 설정 화면: 학습 설정·정보·데이터 관리를 섹션 카드로 묶음, 저장 버튼은 카드 오른쪽 아래
5. `c49dddc`, `13ff4de` 라벨·토글 배경을 투명 처리하고 사이드바 선택 테두리 제거, 분야별 진도 배경을 카드와 맞춤

**설계 문서**
- UI 설계서 v1.5 초안: `ai-agent/claude/분석_261111_UI설계서 v1.5.md`. 2.1 메인 윈도우, 2.2 홈, 2.3 퀴즈, 2.4 단어, 2.5 설정, 4장 색상·폰트를 새 구성으로 바꿨다.
