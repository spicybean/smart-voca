## 이슈 1. [Feature] 첫 실행 시 설정 화면 우선 표시와 저장 예외 구현 (FR-2.1)

## 문제
첫 실행 시 DB를 초기화한 뒤 설정 화면을 거치지 않고 홈으로 간다. 설정 화면의 [저장]은 값이 바뀌어야 활성화되어 첫 실행 예외(변경 없이 저장)가 없다.

## 영향 범위
- `src/main.py`: 초기화 분기 이후 첫 화면 결정 (38~40행 부근)
- `src/ui/main_window.py`: 첫 실행 여부 전달
- `src/ui/settings_widget.py`: `_set_dirty` (저장 버튼 활성 규칙)

## 기대 결과
첫 실행 시 설정 화면을 먼저 띄우고, [저장]은 항상 활성화한다. 저장 후 홈으로 이동한다 (UI 3.1, FR-2.1, P-01 4번).

## 이슈 2. [Feature] 퀴즈 세션 중 삭제된 단어의 문항 건너뛰기 구현 (FR-3.6)

## 문제
퀴즈 진행 중 단어를 삭제했을 때 세션에서 해당 문항을 건너뛰는 처리가 없다. `src/services/quiz_service.py`와 `src/ui/quiz_widget.py`에서 관련 로직을 찾지 못했다. 요구사항에는 규칙이 있다 (FR-3.6, UI 2.3.5).

## 영향 범위
- `src/services/quiz_service.py`: 세션 문항 조회·제출
- `src/services/word_service.py`: `delete_word`
- `src/ui/quiz_widget.py`: 문항 표시와 진행 상태

## 기대 결과
삭제된 단어의 문항은 건너뛰고 세션은 유지한다. 남은 문항 수와 진행 표시를 갱신한다 (FR-3.6, P-12).

## 이슈 3. [Feature] 중복 예문 안내 대화상자 구현 (FR-1.6, UI 2.4.2·2.6)

## 문제
`add_user_example`은 같은 문장이 있으면 오류 없이 기존 행을 반환한다. UI 설계서 v1.7이 정한 중복 예문 안내 대화상자가 없다 (`src/ui/message_boxes.py`에 없음).

## 영향 범위
- `src/services/example_service.py`: `add_user_example`의 중복 처리 방식
- `src/ui/message_boxes.py`: 중복 예문 대화상자 추가
- `src/ui/word_detail_dialog.py`: 호출부

## 기대 결과
같은 문장을 추가하면 안내 대화상자를 띄우고 저장하지 않는다 (FR-1.6, P-06 예외 처리).

## 이슈 5. [Refactor] CLAUDE.md 한글 네이밍 규칙의 방법론 참조 정정

## 문제
CLAUDE.md 26행과 133행은 "방법론 §4.2 한글 네이밍"을 가리킨다. 방법론에는 §4.2가 없고, §4는 영문 이름 규칙(`{Project_Name}_{EN_Name}_vX.X_YYMMDD.md`)만 정한다. 프로젝트의 한글 규칙과 충돌한다.

## 영향 범위
- `CLAUDE.md`: 26행, 133행, 문서 관리 규칙

## 기대 결과
한글 네이밍을 프로젝트 예외 규칙으로 명시하고 방법론 참조를 바르게 적는다. 또는 방법론 기준으로 통일한다. 둘 중 방향 결정이 필요하다.
