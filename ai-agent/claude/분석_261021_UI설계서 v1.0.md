# 스마트보카 UI 설계서

**파일 위치**: `ai-agent/claude/분석_261021_UI설계서 v1.0.md`
**작성일**: 2026-10-21
**버전**: v1.0
**설명**: PyQt 기반 사용자 인터페이스 설계

---

## 1. 개요

### 1.1 UI 철학
- **직관성**: 비개발자도 쉽게 사용
- **일관성**: 모든 화면에서 동일한 패턴
- **응답성**: 버튼 클릭 즉시 반응
- **최소화**: 불필요한 요소 제거

### 1.2 화면 구성

스마트보카는 **탭 기반 인터페이스**로 4개 화면 제공:

1. 홈 (Home) - 대시보드
2. 퀴즈 (Quiz) - 퀴즈 풀이
3. 단어 (Word) - 단어 관리
4. 설정 (Settings) - 학습 설정

---

## 2. 화면 설계

### 2.1 메인 윈도우 (MainWindow)

**기본 정보**:
- 윈도우 크기: 1000 x 700 (고정)
- 제목: "스마트보카"
- 태스크바 아이콘: 앱 로고

**레이아웃**:
```
┌─────────────────────────────────────────┐
│ 스마트보카                      [_][□][✕] │
├─────────────────────────────────────────┤
│ [홈] [퀴즈] [단어] [설정]                │ ← 탭 바
├─────────────────────────────────────────┤
│                                         │
│          현재 탭의 내용                  │
│          (Home/Quiz/Word/Settings)      │
│                                         │
│                                         │
└─────────────────────────────────────────┘
```

**주요 요소**:
- 상단: 윈도우 제목 + 최소/최대/닫기 버튼
- 중단: 탭 메뉴 (4개)
- 하단: 탭별 콘텐츠

## 3. 사용자 플로우 (User Flow)

### 3.1 첫 실행 플로우

```
앱 시작
  ↓
DB 확인
  ├─ DB 없음 → 자동 초기화 (init_db.py)
  └─ DB 있음 → 계속
  ↓
메인 윈도우 표시
  ↓
홈 화면 표시 (진도율 0~100%)
  ↓
[퀴즈 시작하기] 또는 [설정] 클릭 가능
```

### 3.2 일반적인 학습 플로우

```
홈 화면
  ↓
[퀴즈 시작하기] 클릭
  ↓
퀴즈 준비 화면
  ↓
[퀴즈 시작하기] 클릭
  ↓
문제 1~N 풀이 (양방향: 한→영, 영→한)
  ├─ 정답 → ✓ 표시, 데이터 저장
  └─ 오답 → ✗ 표시, 데이터 저장
  ↓
[다음 문제] 클릭 반복
  ↓
N개 완료
  ↓
보너스 문제 화면
  ├─ [보너스 도전하기] → 보너스 퀴즈 진행
  └─ [건너뛰기] → 결과 화면
  ↓
결과 화면 (정답률, 진도 표시)
  ↓
[홈으로] 또는 [다시 풀기] 클릭
  ↓
홈 화면 (진도율 업데이트)
```

### 3.3 단어 관리 플로우

```
단어 탭 클릭
  ↓
단어 목록 표시 (20개/페이지)
  ↓
┌─ [검색] 클릭 → 검색 입력 → 결과 필터링
│
├─ [필터] 클릭 → 분야 선택 → 필터링
│
├─ [+ 추가] 클릭 → 팝업
│   ├─ 영어/한글/분야 입력
│   ├─ [저장] → 단어 추가
│   └─ 예문 자동 조회 (API)
│
├─ 단어 행 클릭 → 상세 보기
│   ├─ 예문 표시
│   ├─ 통계 표시
│   ├─ [수정] / [삭제]
│   └─ [닫기]
│
└─ [✕] 버튼 클릭 → 삭제 확인
    └─ [확인] → 단어 삭제
```

## 4. 색상 및 스타일

### 4.1 색상 팔레트

```
Primary (주색): #4CAF50 (초록색)
  - 진행 바, "정답" 표시, 주요 버튼

Secondary: #2196F3 (파란색)
  - 탭 선택, 버튼 호버

Danger: #F44336 (빨간색)
  - "오답" 표시, 삭제 버튼, 경고

Background: #F5F5F5 (밝은 회색)
  - 윈도우 배경

Text: #333333 (검은색)
  - 일반 텍스트

Border: #CCCCCC (연한 회색)
  - 테이블 경계, 구분선
```

### 4.2 폰트

```
제목: 14pt Bold (보기: 13pt, 버튼)
본문: 12pt Regular (테이블, 레이블)
통계: 11pt Regular (소형 텍스트)

폰트 패밀리: Arial, Helvetica, Sans-serif
```

### 4.3 아이콘

| 아이콘 | 용도 |
|--------|------|
| 📚 | 앱 로고, 단어 관리 |
| 🎯 | 퀴즈 |
| 📊 | 통계, 대시보드 |
| 🔥 | 최근 활동, 인기 |
| ⚙️ | 설정 |
| ✓ | 정답 |

## 5. 반응형 요소

### 5.1 버튼 상태

```
기본 상태: 회색, 텍스트 검은색
마우스 오버: 밝은 회색, 커서 변경
클릭: 더 어두운 색
비활성화: 회색 + 50% 투명도
```

### 5.2 입력 필드

```
기본: 흰색 배경, 검은색 테두리
포커스: 파란색 테두리, 2px 두께
오류: 빨간색 테두리
```

### 5.3 진행 바

```
배경: 연한 회색
진행: Primary 색상 (초록색)
텍스트: 검은색 (중앙)
높이: 20px
```

## 6. 접근성 (Accessibility)

- 모든 버튼에 마우스 오버 시 도움말 (Tooltip)
- 탭 키로 요소 간 이동 가능
- 키보드 단축키 (선택사항):
  - Ctrl+Q: 퀴즈 시작
  - Ctrl+W: 단어 관리
  - Ctrl+S: 설정
  - Enter: 선택지 확인 (퀴즈 중)
