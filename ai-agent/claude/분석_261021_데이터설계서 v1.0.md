## 2. 테이블 상세 정의

### 2.1 Word 테이블

**목적**: 학습 대상 영단어 저장

**SQL 스키마**:
```sql
CREATE TABLE Word (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    english VARCHAR(100) NOT NULL UNIQUE,
    korean_meaning VARCHAR(100) NOT NULL,
    category VARCHAR(50) NOT NULL DEFAULT '일상',
    level INTEGER DEFAULT 1 CHECK(level >= 1 AND level <= 5),
    created_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    is_deleted BOOLEAN DEFAULT 0
);

CREATE INDEX idx_word_english ON Word(english);
CREATE INDEX idx_word_category ON Word(category);
```

**필드 정의**:

| 필드명 | 타입 | 제약조건 | 설명 |
|--------|------|---------|------|
| id | INTEGER | PK, AI | 고유 ID |
| english | VARCHAR(100) | NOT NULL, UNIQUE | 영문 단어 (중복 불가) |
| korean_meaning | VARCHAR(100) | NOT NULL | 한글 뜻 |
| category | VARCHAR(50) | NOT NULL, DEFAULT '일상' | 분야 (일상/비즈니스) |
| level | INTEGER | DEFAULT 1, CHECK(1~5) | 난이도 (1~5) |
| created_date | DATETIME | DEFAULT NOW | 생성일시 |
| updated_date | DATETIME | DEFAULT NOW | 수정일시 |
| is_deleted | BOOLEAN | DEFAULT 0 | 소프트 삭제 플래그 |

**샘플 데이터**:
```
id | english | korean_meaning | category | level | created_date
1  | apple   | 사과           | 일상     | 1     | 2026-10-21
2  | banana  | 바나나         | 일상     | 1     | 2026-10-21
3  | interview | 면접         | 비즈니스 | 2     | 2026-10-21
```

### 2.2 Example 테이블

**목적**: 각 단어별 예문 저장

**SQL 스키마**:
```sql
CREATE TABLE Example (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    word_id INTEGER NOT NULL,
    sentence VARCHAR(500) NOT NULL,
    source VARCHAR(20) NOT NULL DEFAULT 'api',
    created_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (word_id) REFERENCES Word(id) ON DELETE CASCADE
);

CREATE INDEX idx_example_word_id ON Example(word_id);
```

**필드 정의**:

| 필드명 | 타입 | 제약조건 | 설명 |
|--------|------|---------|------|
| id | INTEGER | PK, AI | 고유 ID |
| word_id | INTEGER | NOT NULL, FK | Word 테이블 참조 |
| sentence | VARCHAR(500) | NOT NULL | 예문 텍스트 |
| source | VARCHAR(20) | DEFAULT 'api' | 출처 (api/user/cache) |
| created_date | DATETIME | DEFAULT NOW | 생성일시 |

**샘플 데이터**:
```

1  | 1       | I eat an apple every day. | api
2  | 1       | New York is called the Big Apple. | api
```

### 2.3 Progress 테이블

**목적**: 학생의 단어별 학습 진도 저장

**SQL 스키마**:
```sql
CREATE TABLE Progress (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    word_id INTEGER NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT '미학습',
    correct_count INTEGER DEFAULT 0,
    wrong_count INTEGER DEFAULT 0,
    correct_rate REAL DEFAULT 0.0,
    last_reviewed_date DATETIME,
    next_review_date DATETIME,
    created_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_date DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (word_id) REFERENCES Word(id) ON DELETE CASCADE
);

CREATE INDEX idx_progress_word_id ON Progress(word_id);
CREATE INDEX idx_progress_status ON Progress(status);
CREATE INDEX idx_progress_next_review ON Progress(next_review_date);
```

**필드 정의**:

| 필드명 | 타입 | 제약조건 | 설명 |
|--------|------|---------|------|
| id | INTEGER | PK, AI | 고유 ID |
| word_id | INTEGER | NOT NULL, FK | Word 테이블 참조 |
| status | VARCHAR(20) | NOT NULL, DEFAULT '미학습' | 상태 (미학습/학습중/복습필요/숙달) |
| correct_count | INTEGER | DEFAULT 0 | 정답 횟수 |
| wrong_count | INTEGER | DEFAULT 0 | 오답 횟수 |
| correct_rate | REAL | DEFAULT 0.0 | 정답률 (0~100) |
| last_reviewed_date | DATETIME | NULL | 마지막 복습일 |
| next_review_date | DATETIME | NULL | 다음 복습 예정일 |
| created_date | DATETIME | DEFAULT NOW | 생성일시 |
| updated_date | DATETIME | DEFAULT NOW | 수정일시 |

**상태 전이 규칙**:
```
미학습
  ↓ (정답 1회)
학습중 (correct_rate >= 70%)
  ↓ (계속 학습)
복습필요 (correct_rate < 70%)
  ↓ (정답 계속)
숙달 (correct_rate >= 80% + 30일 이상)
```

**샘플 데이터**:
```
id | word_id | status | correct_count | wrong_count | correct_rate | next_review_date
1  | 1       | 학습중 | 5             | 2           | 71.4         | 2026-10-22
2  | 2       | 복습필 | 3             | 2           | 60.0         | 2026-10-21
3  | 3       | 미학습 | 0             | 0           | 0            | NULL
```

## 3. 테이블 관계도 (ERD)

## 4. 주요 쿼리 패턴

### 4.1 오늘의 퀴즈 구성 (복합 쿼리)

```sql
-- 새 단어 또는 약한 단어 (50~70%)
SELECT * FROM Word w
JOIN Progress p ON w.id = p.word_id
WHERE w.category = ?
  AND (p.status = '미학습' OR p.correct_rate < 70%)
ORDER BY RANDOM()
LIMIT ?;

-- 복습 예정 단어 (20~30%)
SELECT * FROM Word w
JOIN Progress p ON w.id = p.word_id
WHERE w.category = ?
  AND p.next_review_date = CURRENT_DATE
ORDER BY RANDOM()
LIMIT ?;

-- 자주 틀린 단어 (10~20%)
SELECT * FROM Word w
JOIN Progress p ON w.id = p.word_id
WHERE w.category = ?
  AND p.correct_rate < 60%
  AND p.last_reviewed_date <= DATE('now', '-7 days')
ORDER BY p.correct_rate ASC
LIMIT ?;
```

### 4.2 4지선다형 보기 생성

```sql
SELECT english, korean_meaning FROM Word
WHERE category = ? 
  AND level BETWEEN ? AND ?
```

### 4.3 보너스 문제 선정

```sql
-- 정답률 < 60% AND 마지막 복습 >= 7일
SELECT * FROM Word w
JOIN Progress p ON w.id = p.word_id
WHERE p.correct_rate < 60
  AND p.last_reviewed_date <= DATE('now', '-7 days')
ORDER BY p.correct_rate ASC, p.last_reviewed_date ASC
LIMIT 5;
```

### 4.4 홈 화면 통계

```sql
-- 전체 진도율
SELECT 
  COUNT(*) as total_words,
  COUNT(CASE WHEN status = '숙달' THEN 1 END) as completed,
  (COUNT(CASE WHEN status = '숙달' THEN 1 END) * 100.0 / COUNT(*)) as progress_rate
FROM Progress;

-- 오늘 학습할 단어
SELECT COUNT(*) as today_words
FROM Progress
WHERE next_review_date = CURRENT_DATE
  OR status = '미학습';

-- 분야별 진도
SELECT 
  category,
  COUNT(*) as total,
  COUNT(CASE WHEN status = '숙달' THEN 1 END) as completed,
  (COUNT(CASE WHEN status = '숙달' THEN 1 END) * 100.0 / COUNT(*)) as rate
FROM Word w
JOIN Progress p ON w.id = p.word_id
GROUP BY category;
```

## 7. 데이터 무결성

### 7.1 제약조건

| 제약조건 | 설명 |
|---------|------|
| PRIMARY KEY | 각 테이블의 id는 유일 |
| FOREIGN KEY | Word - Example/Progress/Quiz 관계 유지 |
| UNIQUE | Word.english 중복 불가 |
| CHECK | level 1~5, daily_word_count >= 1 |
| DEFAULT | 기본값 설정으로 NOT NULL 보장 |

---

### 7.2 트랜잭션 관리

```python
# SQLAlchemy 예시
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker

engine = create_engine('sqlite:///data/smart_voca.db')
Session = sessionmaker(bind=engine)
session = Session()

try:
    session.add(new_quiz_record)
    session.commit()  # 정상 완료
except Exception as e:
    session.rollback()  # 오류 발생 시 롤백
    raise
finally:
    session.close()
```
