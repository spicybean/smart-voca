# 스마트보카 기능 분해도

**파일 위치**: `ai-agent/claude/설계_261125_기능 분해도 v0.1.md` (초안, `docs/` 승격은 승인 후)
**작성일**: 2026-11-25
**버전**: v0.1
**설명**: 요구사항 명세서 v1.10의 FR을 원자 기능 단위로 나누고, 각 기능을 프로세스(P-xx), 화면(UI), 구현 위치와 연결한 기능 분해도 (방법론 §2.3 Function Map)

---

## 1. 목적과 읽는 법

- **목적**: 요구사항 FR이 어떤 원자 기능으로 구현되는지, 그 기능이 어느 프로세스·화면·모듈에 놓이는지 한 표에서 추적한다.
- **ID 규칙**: `F-대분류.중분류.소분류`. 요구사항 FR 번호와 맞춘다. 예) `F-3.3.2` = FR-3.3의 두 번째 원자 기능
- **원자 기능**: 입력 하나, 결과 하나로 설명되는 최소 단위. 하나의 함수가 여러 원자 기능을 담을 수도 있고, 여러 함수가 하나의 원자 기능을 이룰 수도 있다.
- **정본**: 규칙 수치는 요구사항 명세서 v1.10, 처리 순서는 기능 프로세스 설계서 v0.7, 함수 계약은 시스템 구조 설계서 v1.9를 따른다. 이 문서는 그 세 문서를 연결만 한다.

1. **F-3.6.4 구현 누락 가능성**: 세션 중 삭제된 단어를 건너뛰는 로직을 `quiz_service.py`에서 검색했으나 찾지 못했다. 요구(FR-3.6, UI 2.3.5)에는 있으므로 구현 여부를 확인해야 한다.
2. **F-0.1.2, F-2.1.3 구현 위치**: 첫 실행 분기와 첫 실행 저장 예외를 `main_window.py`, `settings_widget.py`에서 검색했으나 찾지 못했다. 다른 파일에 있거나 미구현일 수 있다.
3. **F-0.3.2 상수 목록**: `config.py`의 상수 이름은 확인하지 않았다. 목록은 역할만 적었다.
4. **요구사항 명세서 8장 추적 매트릭스**: 기획 기능 → FR 매핑만 있고, 담당 열이 모두 비어 있다. 이 문서의 원자 기능 ID를 추적에 쓰도록 연결하는 작업이 남아 있다.
5. **화면 번호 확인**: 화면 절 번호(2.3.1, 2.3.2 등)는 UI 설계서 v1.9의 목차 기준으로 적었다. 목차와 대조한 것은 아니다.
