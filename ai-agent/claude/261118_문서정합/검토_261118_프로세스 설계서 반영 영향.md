**작성일**: 2026-11-18
**버전**: v0.2
**설명**: `설계_261118_기능 프로세스 설계서 v0.2.md`를 문서 세트에 넣었을 때 기획·분석·설계 문서에서 바뀌는 부분을 정리한다. v0.1 검토를 갱신했다. 기획·설계·데이터 작업본은 이 검토에 맞춰 수정했고, 요구사항과 UI는 결정 사항만 남겼다.

## 1. 결론

1. **분류**: 기능별 처리 순서는 방법론의 **프로세스 설계서**(설계 단계)다. 파일명을 `설계_`로 바꿨다.
2. **중복 정리**: 처리 절차는 프로세스 설계서에 한 곳만 두고, 규칙 수치는 요구, 저장 구조는 데이터, 함수 계약은 설계에 둔다. 기획서 3.1절과 10.4절, 설계 4.2~4.5절과 4.11절의 절차 문장, 데이터 5.1·5.2·7.3절의 절차를 옮겼다.
3. **요구에 없는 내용 제거**: 요구사항에 근거가 없던 기준과 규칙은 문서에서 뺐다. 이 과정에서 설계 4.1의 `WEAK_RATE_THRESHOLD`는 출처를 "미정"으로 고쳤다.
4. **요구사항 필수 수정 2건**이 남아 있다. 요구사항은 아직 수정하지 않았다.

- 5.1 초기화 코드 블록을 저장 정책 목록으로 바꿨다. 절차는 P-01을 따른다.
- 5.2 복구 절차를 검증 기준만 남기고 P-15로 옮겼다.
- 7.3 SQLAlchemy 코드 블록을 삭제했다 (CLAUDE.md의 소스 코드 금지 규칙). 답변 트랜잭션은 P-09를 따른다.

### 3.3 UI 설계서 v1.6 — 결정 대기
