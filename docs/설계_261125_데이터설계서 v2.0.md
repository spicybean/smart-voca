# 스마트보카 데이터 설계서

**파일 위치**: `docs/설계_261125_데이터설계서 v2.0.md`
**작성일**: 2026-11-25
**버전**: v2.0
**설명**: SQLite 테이블, 컬럼, 제약, 관계, 저장 정책을 정의한다. 실제 정의는 `app/models.py`와 일치한다. 요구는 요구사항 명세서 v2.0을 따른다.

---

## 1. 개요

- DB: SQLite 파일 하나. 경로는 `DB_PATH` (기본 `data/voca.db`, 서버 `/data/voca.db`).
- 테이블은 첫 실행 때 `db.create_all()`로 자동 생성된다 (VOCA-NFR-003).
- 시간은 로컬 시각 `datetime.now()`로 저장한다.
- 로그인이 없으므로 사용자 항목은 기본 사용자 `DEFAULT_USER_ID = 1`로 고정한다.

## 3. 테이블 정의

### 3.1 word

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| id | INTEGER | PK | 등록 순서. 일차 계산의 기준 |
| english_key | VARCHAR(64) | NOT NULL, UNIQUE | 중복 검사 키: 공백 정리 후 소문자 |
| english | VARCHAR(64) | NOT NULL | 표시용 영단어 (공백 정리) |
| meaning | VARCHAR(200) | NOT NULL | 뜻 |
| created_at | DATETIME | NOT NULL | 등록 시각 |

- 검증 규칙: english는 영문자·공백·하이픈·아포스트로피, 64자 이하. meaning은 비어 있으면 안 되고 200자 이하.
- 중복: english_key가 같으면 거부 (대소문자·공백 무시).

### 3.2 study_log

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| id | INTEGER | PK | |
| user_id | INTEGER | NOT NULL, 기본 1 | 사용자 (로그인 전까지 고정) |
| word_id | INTEGER | NOT NULL, FK word.id ON DELETE CASCADE, 인덱스 | 단어 |
| day_no | INTEGER | NOT NULL | 일차 번호 |
| action | VARCHAR(10) | NOT NULL | `known` (외웠어요) 또는 `again` (아직이에요) |
| created_at | DATETIME | NOT NULL | 응답 시각 |

- 단어가 삭제되면 기록도 함께 삭제된다. 모든 SQLite 연결에서 `PRAGMA foreign_keys=ON`을 켜고, `ON DELETE CASCADE`로 동작한다 (이슈 #8 수정). 이슈로 관리 (5장).
- 현재 일차 = max(day_no). 암기 수 = action이 known인 단어 id의 고유 개수.

### 3.3 exam_session

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| id | INTEGER | PK | 회차 번호 |
| user_id | INTEGER | NOT NULL, 기본 1 | |
| question_count | INTEGER | NOT NULL | 실제 출제 문항 수 (단어 수가 적으면 줄어듦) |
| direction_mode | VARCHAR(10) | NOT NULL | `en_ko`, `ko_en`, `mix` |
| formats | VARCHAR(40) | NOT NULL | 선택 형식을 쉼표로 이어 씀 (예: `mc,short,ox`) |
| position | INTEGER | NOT NULL, 기본 0 | 현재 풀고 있는 문항 번호 (0부터) |
| status | VARCHAR(10) | NOT NULL, 기본 `active` | `active` 또는 `done` |
| created_at | DATETIME | NOT NULL | 시작 시각 |
| finished_at | DATETIME | NULL | 끝낸 시각 (done일 때만) |

- 관계: exam_session 1 : N exam_item. 세션 삭제 시 문항도 삭제 (cascade).

### 3.4 exam_item

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| id | INTEGER | PK | |
| session_id | INTEGER | NOT NULL, FK exam_session.id ON DELETE CASCADE, 인덱스 | 회차 |
| position | INTEGER | NOT NULL | 문항 순서 (0부터) |
| word_id | INTEGER | NOT NULL, FK word.id ON DELETE CASCADE, 인덱스 | 단어 |
| direction | VARCHAR(10) | NOT NULL | `en_ko` 또는 `ko_en` |
| fmt | VARCHAR(10) | NOT NULL | `mc`, `short`, `ox` |
| prompt | VARCHAR(300) | NOT NULL | 화면에 보인 문제 (영단어 또는 뜻) |
| expected | VARCHAR(300) | NOT NULL | 정답. OX는 `O` 또는 `X` |
| choices | TEXT | NULL | 4지선다 보기 목록(JSON), OX는 제시한 뜻 한 개(JSON) |
| given | VARCHAR(300) | NULL | 사용자 응답 |
| is_correct | BOOLEAN | NULL | 정오 (응답 전에는 NULL) |
| answered_at | DATETIME | NULL, 인덱스 | 응답 시각 |

- 통계는 `is_correct`와 `answered_at`으로 계산한다. 날짜별 정답률은 `date(answered_at)`로 묶는다.

### 3.5 setting

| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| key | VARCHAR(40) | PK | 설정 이름. 현재 `daily_amount`만 사용 |
| value | VARCHAR(200) | NOT NULL | 값 (문자열로 저장) |

- `daily_amount`: 5~50. 값이 없으면 기본 20.

## 4. 관계 요약

```
word 1 ── N study_log      (word_id, CASCADE)
word 1 ── N exam_item      (word_id, CASCADE)
exam_session 1 ── N exam_item  (session_id, CASCADE)
setting: 독립 키-값
```

---

## 5. 저장 정책

| 항목 | 정책 |
|---|---|
| 단어 삭제 | 해당 단어의 `study_log`, `exam_item`까지 삭제 (외래키 cascade). 화면에 기록도 지워진다고 안내 |
| 시험 중 단어 삭제 | 그 단어의 `exam_item`은 cascade로 함께 지워진다. 회차의 남은 문항만 계속 출제되고, 전체 문항 수도 줄어든다 (이슈 #9 수정) |
| CSV 가져오기 | 같은 영단어는 건너뛴다. 실패는 한 줄씩 보고하고 나머지는 저장한다 (줄 단위 커밋) |
| 백업 | 이번 버전에서 제공하지 않는다. 서버에서는 `/data` 볼륨이 데이터를 지킨다 |
| 개인정보 | 실명, 학번을 저장하지 않는다. 사용자 항목은 기본 사용자 1 |

## 6. 초기 데이터

- 첫 실행 시 DB는 비어 있다. 단어는 `/words/import`에서 CSV로 등록한다.
- 제공 샘플: 저장소 루트 `단어사전_샘플.csv` (`영단어,뜻`, 1,999행). 2026-11-25에 원본의 두 오류를 고쳤다. 1459줄 `gin하해` → `ginkgo`, 중복 `peck`(1422줄, 1549줄)은 한 줄로 합쳤다. 등록 결과 1,999개 추가, 중복·형식 오류 없음 (테스트로 확인).
