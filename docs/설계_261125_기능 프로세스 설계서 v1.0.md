## 2. 프로세스 상세

### P-01 단어 등록
1. 영단어와 뜻을 받는다.
2. 공백을 정리하고 검증한다 (영단어 형식 64자, 뜻 필수 200자). 실패하면 메시지 후 목록으로.
3. 중복 키(소문자, 공백 정리)를 찾는다. 있으면 "이미 등록된 단어입니다" 메시지.
4. 저장하고 커밋한다.

### P-02 단어 목록·검색
1. 검색어가 있으면 영단어 또는 뜻에 포함된 단어만 고른다 (대소문자 무시).
2. 영단어 순으로 정렬해 표시한다.

### P-03 단어 수정
1. 단어가 없으면 404.
2. 새 값을 검증한다. 다른 단어와 영단어가 겹치면 거부.
3. 저장하고 커밋한다. 기록은 그대로 둔다.

### P-04 단어 삭제
1. 단어를 찾는다 (없으면 404).
2. 단어를 삭제한다. 연결마다 켜 두는 SQLite 외래키 설정으로 `study_log`, `exam_item` 기록도 함께 지워진다 (이슈 #8 수정).
3. 커밋하고 "기록도 함께 지워집니다" 메시지를 띄운다.

### P-05 CSV 일괄 등록
1. 파일을 읽는다. UTF-8(BOM 허용)이 아니면 거부. 20MB 초과는 413 화면.
2. 첫 줄은 제목으로 건너뛴다.
3. 줄마다 열 2개를 확인하고 검증한다. 실패 줄은 "N줄 (단어): 사유"로 기록하고 넘어간다.
4. 키가 DB에 있거나 이번 파일에서 이미 나왔으면 중복으로 기록하고 넘어간다.
5. 나머지는 추가하고, 끝에 한 번 커밋한다.
6. 결과 화면: 추가 수, 중복 목록, 오류 줄 목록.

### P-06 일차 카드 구성
1. 단어가 없으면 빈 화면 (등록 안내).
2. 하루 학습량 `N`을 읽는다. 전체 일차 수 = ceil(단어 수 / N).
3. 요청한 일차가 범위 밖이면 404.
4. 기본 목록: id 순서의 `(일차-1)×N` 번째부터 N개.
5. 복습: 일차가 2 이상이면 그 앞 단어에서 `max(1, round(N×0.2))`개를 `random.Random("day-일차")`로 뽑아 더한다.
6. 자주 틀린 단어 상위 3개 중 목록에 없는 것을 더한다.
7. 같은 시드로 섞는다. 카드 인덱스 `i`가 목록 길이를 넘으면 "일차 끝" 화면.

### P-07 카드 응답 기록
1. 응답 값은 `known` 또는 `again`만 허용.
2. 단어가 없으면 거부.
3. 기록을 `study_log`에 추가하고 커밋. 다음 카드(`i+1`)로 이동.

### P-08 시험 회차 생성
1. 문제 수는 1~50, 방향은 `en_ko`, `ko_en`, `mix` 중 하나, 형식은 `mc`, `short`, `ox` 중 하나 이상.
2. 단어가 4개 미만이면 거부.
3. 가중치를 계산한다 (규칙은 시스템 구조 설계서 5.2).
4. 문제 수만큼 중복 없이 고른다 (단어 수가 적으면 단어 수만큼).
5. 문항마다 방향(mix면 무작위)과 형식(선택 중 무작위)을 정한다.
6. 4지선다는 보기 4개를 만들고 뜻이 같은 단어는 뺀다. 보기가 모자라면 단답형으로 바꾼다.
7. OX는 진짜 뜻 또는 다른 단어의 뜻을 무작위로 제시하고 정답(O/X)을 정한다.
8. 회차와 문항을 한 번에 저장한다.

### P-09 문항 응답·채점
1. 회차가 끝났으면 거부.
2. 응답을 채점한다.
   - mc: 보기 문자열과 정답 문자열이 같으면 정답.
   - short: 정규화 후 비교. 뜻은 구분자로 나눠 한 조각이라도 맞으면 정답.
   - ox: 응답이 정답 기호(O/X)와 같으면 정답.
3. 문항에 응답, 정오, 응답 시각을 기록한다.
4. 회차 위치를 한 칸 옮긴다. 마지막 문항이면 회차를 `done`으로 바꾸고 끝난 시각을 남긴다.
5. 한 번 커밋한다.

### P-10 시험 결과 집계
1. 정답 수 = 정오가 참인 문항 수. 전체 = 문항 수.
2. 정답률 = 정답 수 ÷ 전체 × 100 (반올림).
3. 틀린 문항 목록 (문제, 내 답, 정답).

### P-11 학습 통계 집계
1. 현재 일차 = 카드 기록의 최대 일차 (없으면 1). 전체 일차 = ceil(단어 수 / N).
2. 암기 수 = 외웠어요 기록이 있는 단어 수 (고유).
3. 날짜별 정답률 = 응답 날짜(`date(answered_at)`)로 묶어 문항 수, 정답 수, 정답률.
4. 회차별 점수 = 끝난 회차마다 정답 수와 문항 수.
5. 자주 틀린 단어 = 틀린 문항 수가 많은 순 상위 10개.

## 3. 예외 처리

| 상황 | 처리 | 프로세스 |
|---|---|---|
| 영단어 형식 오류 | 메시지, 저장 안 함 | P-01, P-03 |
| 중복 영단어 | 메시지, 저장 안 함 (가져오기에서는 건너뜀) | P-01, P-03, P-05 |
| CSV 형식 오류 줄 | 줄 번호와 사유 기록, 나머지 계속 | P-05 |
| CSV 인코딩 오류 | UTF-8 안내 메시지 | P-05 |
| 업로드 20MB 초과 | 413 화면 | P-05 |
| 일차 범위 밖 | 404 | P-06 |
| 단어가 4개 미만 | 시험 시작 거부, 안내 | P-08 |
| 형식 미선택 | 시험 설정 화면에 메시지 | P-08 |
| 이미 끝난 회차에 답 | 거부 | P-09 |
| 시험 중 단어 삭제 | 그 단어의 문항은 기록과 함께 지워져 전체 문항 수가 줄어든다. 현재 문항의 단어가 지워지면 다음 미답 문항이 나온다 (이슈 #9 수정) |

|---|---|
| P-01, P-03, P-04 | 단건 변경 한 번 커밋 |

## 5. 열린 사항
1. 단어를 삭제하면 `exam_item`도 함께 지워진다 (이슈 #8 수정, 외래키 ON).
   - 시험 진행 중 삭제된 단어의 문항은 목록에서 빠진다. 현재 문항을 풀 차례인 문항 = 아직 답하지 않은 첫 문항 (이슈 #9 수정). 전체 문항 수도 빠진 만큼 줄어든다. 남은 문항이 없으면 회차가 끝난다.
2. 복습 비율(20%)과 자주 틀린 단어 개수(3개)는 고정값이다. 도전 기능의 설정에서 바꿀 수 있게 할지 정해야 한다.
