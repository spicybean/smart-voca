# 스마트보카 프로젝트 기획서

**파일 위치**: `docs/기획_261125_스마트보카 프로젝트 기획서 v2.0.md`
**작성일**: 2026-11-25
**버전**: v2.0
**설명**: 영단어 등록, 일차별 암기, 시험, 통계를 제공하는 웹 앱의 프로젝트 기획서. 기말과제 요건에 맞춰 PyQt6 데스크톱 기획(v1.x)을 웹 앱 기획으로 바꿨다. 요구 상세는 요구사항 명세서 v2.0을 본다.

---

## 1. 프로젝트 개요

### 1.1 프로젝트명
스마트보카 (Smart-Voca)

### 1.2 한 줄 설명
등록한 영단어를 하루 학습량 단위의 일차로 나눠 외우고, 시험과 통계로 확인하는 웹 앱

### 1.3 배경과 목적
- 단어장 암기는 반복 주기가 없어 복습이 빠지기 쉽다. 일차 단위로 나누고, 이전 일차와 자주 틀린 단어를 섞어 복습을 돕는다.
- 시험 결과를 DB에 남겨 어떤 단어가 약한지 통계로 보여 준다.
- 과제 목표: 수업 중 만든 단어장 프로그램을 웹 앱으로 다시 만들고, 학교 서버에 올려 실행한다. 문서와 코드를 함께 키운 흔적을 남긴다.

### 1.4 대상 사용자
- 영단어를 개인적으로 공부하는 학생 1인. 로그인 없이 같은 기기에서 쓴다 (계정 기능은 도전 범위로 미구현).

## 2. 비즈니스 요구사항 (BRD)

| 목표 | 성공 기준 |
|---|---|
| 단어 관리 | 직접 입력과 CSV 일괄 등록으로 단어를 넣고, 목록·검색·수정·삭제가 된다 |
| 암기 | 하루 학습량대로 일차가 나뉘고, 카드를 넘기며 외웠는지 기록된다 |
| 시험 | 문제 수, 방향, 형식을 골라 풀고, 점수와 틀린 문항을 본다 |
| 통계 | 현재 일차, 암기 수, 날짜별 정답률, 자주 틀린 단어를 DB 이력으로 본다 |
| 배포 | 학교 서버 조건(Dockerfile, 0.0.0.0:8080, UID 10001)에서 실행되고 점검 워크플로가 통과한다 |

---

## 3. 시스템 범위

### 3.1 포함
- 단어 등록, 조회, 수정, 삭제, 검색, CSV 일괄 등록
- 하루 학습량 설정, 일차 암기 카드, 기록 저장
- 시험 (4지선다, 단답형, OX / 영→한, 한→영, 섞기 / 가중치 출제)
- 시험 이력, 통계 (진척, 날짜별 정답률, 회차별 점수, 자주 틀린 단어)
- 서버 이미지와 점검 워크플로

### 3.2 제외 (이번 버전)
- 로그인과 계정별 이력, 다른 계정 이력 보기 (도전)
- 복습 비율·시험 기본값 설정 화면 (도전)
- 데스크톱 앱, 백업·복구 화면, 분야·수준 분류, 보너스 문제 (v1.x에서 제거)
- 외부 사전 API, 음성, 모바일 앱

## 4. 기술 환경

| 구분 | 선택 |
|---|---|
| 언어 | Python 3.13 |
| 웹 프레임워크 | Flask 3.1 (서버 템플릿과 HTML 폼, 자바스크립트 없음) |

| 테스트 | pytest 9.2 |
| 배포 | Dockerfile (python:3.13-slim), 학교 서버 |

---

## 5. 핵심 흐름

1. **단어 준비**: `/words`에서 직접 입력하거나 `/words/import`에서 CSV를 올린다.
2. **암기**: `/memorize`에서 오늘의 일차 카드를 넘긴다. 외웠으면 기록되고, 일차가 끝나면 다음 일차로 간다.
3. **시험**: `/exam`에서 문제 수, 방향, 형식을 고르고 푼다. 결과와 틀린 문항을 본다.
4. **확인**: `/`와 `/stats`에서 현재 일차, 암기 수, 정답률을 본다.

## 6. 위험과 대응

| 위험 | 대응 |
|---|---|
| CSV 데이터 오류 (예: `gin하해`) | 형식 검사로 건너뛰고 줄 번호를 보여 준다. 원본 수정은 사용자가 한다 |
| 같은 뜻의 중복 단어 | 중복 정책을 문서화하고 먼저 나온 뜻을 쓴다 |
| 서버 경로 규칙 위반 | 템플릿 테스트로 `/` 기준 링크와 따옴표 속성을 검사한다 |
| 서버에서 쓰기 권한 없음 | DB는 `/data`에만 쓰고, 빌드 단계에서 `/data`를 UID 10001 소유로 만든다 |
| 로그인이 없어 기록이 한 사람 것 | 기록의 `user_id`를 1로 고정. 도전 기능에서 계정 분리 |
