**작성일**: 2026-11-25
**버전**: v1.0
**설명**: 방법론 §2.2 환경 분석서(External Analysis). 웹 앱이 놓이는 사용 환경(학생 PC, 학교 서버), 기술 환경, 외부 데이터, 제약과 위험을 정리한다. 설계 결정은 시스템 구조 설계서의 ADR이 정본이다.

## 1. 목적과 범위
- 웹 앱이 실제로 어떤 환경에서 쓰이는지 정리하고, 기술 선택의 전제를 기록한다.
- 범위 밖: 기존 시스템 현황 (신규 개발이라 현황 분석서는 생략, 4장 참고).

## 2. 사용 환경
| 항목 | 내용 | 근거 |
|---|---|---|
| 사용자 | 영단어를 공부하는 학생. 계정별로 기록을 나눔 | 요구사항 명세서 v2.1 |
| 사용 기기 | PC 크롬 (과제 요건 VOCA-NFR-001) | 과제 요건 |

| 데이터 범위 | 단어, 암기 기록, 시험 기록, 계정 정보 (비밀번호는 해시) | 데이터 설계서 v2.1 |
| 개발 방식 | 1인 개발 + AI 에이전트 (Claude Code) 협업 | CLAUDE.md |

## 3. 기술 환경
### 3.1 소프트웨어
| 구분 | 선택 | 버전 | 근거 |
|---|---|---|---|
| 언어 | Python | 3.13 (이미지 기준) | Dockerfile |
| 웹 프레임워크 | Flask | 3.1.2 | ADR-01 |
| DB 도구 | Flask-SQLAlchemy, SQLAlchemy | 3.1.1, 2.1.8 | ADR-03 |
| 서버 | gunicorn | 23.0.0 | ADR-04 |
| 테스트 | pytest | 9.2.0 | 테스트 정의서 |
| 컨테이너 | Docker, python:3.13-slim | 로컬 Docker 28.0.4 | Dockerfile |

### 3.2 개발 환경
- OS: Windows 11 Pro. 가상환경은 프로젝트의 `venv/`.
- 설치: `pip install -r requirements-dev.txt` (서버 이미지는 `requirements.txt`만 설치).
- 버전 관리: Git, 원격 GitHub 공개 리포. 브랜치는 `main`.
- 시스템 Python에는 의존성이 없으므로 테스트는 venv로 실행한다.

### 3.3 운영 환경
- 학교 서버: 인터넷이 막힌 네트워크, UID 10001, 리눅스 권한 없음, 메모리 1GB, 쓰기는 `/data`와 `/tmp`만 가능.
- 앞단 nginx가 `/2026/voca-<학번>/` 로 주소를 옮기고 HTML 안의 주소를 바꾼다.
- 데이터는 `/data/voca.db` (SQLite). 볼륨이 재시작 후에도 데이터를 지킨다.

| 간격 반복 학습 | 복습 간격을 정답 연속으로 늘림 | v2.0에서 일차와 복습 비율 방식으로 바꿈 (단순화) |

## 5. 외부 데이터
| 데이터 | 규모 | 상태 |
|---|---|---|
| 과제 제공 단어 CSV (`단어사전_샘플.csv`) | 1,999개 (수정 후, 영단어,뜻) | 저장소에 포함. 2026-11-25 두 오류 수정 (`ginkgo`, `peck` 병합) |
| 외부 사전 API | 사용하지 않음 | 예문 기능 없음 (ADR-02) |

## 6. 제약 조건
1. 실행 중 인터넷 접속 불가 (VOCA-NFR, 제출 규칙 R-07). 의존성은 빌드 때 설치한다.
2. 서버 메모리 1GB, 업로드 20MB 이하.
3. DB는 SQLite만 사용 (PostgreSQL은 허락 없이 쓸 수 없음).
4. 비밀값은 환경변수 (`SECRET_KEY`, `DB_PATH`). 코드와 이미지에 넣지 않는다.
5. 이미지 크기 500MB 이하 (로컬 빌드 224MB).

## 7. 위험과 대응
| 위험 | 대응 | 관련 |
|---|---|---|
| 서버에서 쓰기 실패 | `/data`만 쓰고 UID 10001 소유로 만든다 | R-06 |
| 경로가 `/` 기준이 아님 | 템플릿 테스트로 `/` 시작 링크와 따옴표 속성을 검사 | R-04 |
| 입력 데이터 오류 | 형식 검사 후 줄 번호와 함께 건너뜀. 샘플 데이터는 수정 | FR-004 |
| 로그인 없는 공유 PC에서 기록 혼합 | 계정별 기록 분리, 비밀번호 해시 | FR-041~043 |
| 요청 위조 | 세션 토큰 검사 (CSRF) | 이슈 #14 |
| 크롬 화면 차이 | 헤드리스 크롬으로 주요 화면 확인, 나머지는 직접 확인 | 이슈 #13 |
