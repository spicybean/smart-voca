## 6. 의존성
```
설정(config) → DB 모델(models) → 서비스(word, study, exam, stats, settings, auth)
            → 라우트(views) → 템플릿·정적 파일 → 앱 팩토리(__init__) → wsgi.py → Dockerfile
```
- 서비스는 Flask 요청 객체를 받지 않는다. 라우트가 로그인 계정 번호를 넘긴다.
