# 스마트보카 아키텍처 결정 기록 (ADR 등록부)

**파일 위치**: `docs/설계_261125_아키텍처 결정 기록 v1.0.md`
**작성일**: 2026-11-25
**버전**: v1.0
**설명**: 방법론 §2.3 아키텍처 결정 기록(Decision Records)의 등록부. 웹 앱 기준 결정의 번호, 상태, 재검토 조건, 정본 위치를 모은다. 결정의 배경·대안·근거 원문은 시스템 구조 설계서 v2.1 7장이 정본이다.

---

## 1. 쓰는 법
- 새 결정은 시스템 구조 설계서 7장에 `ADR-NN`으로 추가하고, 이 등록부에 한 줄을 더한다.
- 결정을 바꾸면 이전 항목을 지우지 않고 상태를 `대체됨`으로 바꾼 뒤 새 번호를 쓴다.

## 2. 등록부

| ADR-09 | 시험 가중치 출제 | 안 본 단어 우선, 틀린 횟수 가산 | 채택 | 출제 규칙을 바꿀 때 | 기능 프로세스 v1.0 P-08 | `app/exam_service.py` |
