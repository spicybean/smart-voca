# 스마트보카 기능 분해도

**파일 위치**: `docs/설계_261125_기능 분해도 v1.0.md`
**작성일**: 2026-11-25
**버전**: v1.0
**설명**: 방법론 §2.3 기능 분해도(Function Map). 요구사항 명세서 v2.1의 기능을 원자 기능 단위로 나누고, 각 기능을 프로세스(P-xx), 화면(UI), 구현 함수에 연결한다.

---

## 1. 읽는 법
- ID: `F-대분류.중분류.소분류`. 요구 ID와 맞춘다. 예: `F-3.2.1`은 시험 출제의 첫 원자 기능.
- 프로세스(P-xx)는 기능 프로세스 설계서 v1.0, 화면은 UI 설계서 v2.1, 함수는 `app/` 모듈의 함수다.

## 2. 기능 트리
```
F-0 공통 (로그인, 계정, 설정, CSRF)
F-1 단어 관리 (VOCA-FR-001~004)
F-2 암기 (VOCA-FR-011~014)
F-3 시험 (VOCA-FR-021~026)
F-4 학습 통계 (VOCA-FR-031~034)
F-5 도전 기능: 계정과 공개 통계, 설정 (VOCA-FR-041~043, 051~053, 061~062)
```
