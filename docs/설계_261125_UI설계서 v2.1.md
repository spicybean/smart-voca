# 스마트보카 UI 설계서

**파일 위치**: `docs/설계_261125_UI설계서 v2.0.md`
**작성일**: 2026-11-25
**버전**: v2.1
**설명**: 웹 앱 화면 구성, 주소, 화면별 요소와 동작, 메시지, 공통 규칙을 정의한다. 구현 파일은 `app/templates/`, 스타일은 `app/static/style.css`.

---

## 1. 공통 규칙

### 1.1 화면 틀
- 모든 화면은 `base.html`을 쓴다. 상단에 로고(처음 화면으로)와 메뉴(암기, 시험, 단어, 통계).
- 본문 최대 폭 880px. 메시지(성공·실패)는 본문 맨 위에 한 줄로 표시.

### 1.2 주소 규칙 (R-04)
- 모든 주소는 `/`로 시작한다. 호스트(`localhost` 등)를 쓰지 않는다.
- HTML 속성은 따옴표로 감싼다. 템플릿 테스트가 이를 검사한다.
- 자바스크립트 없이 폼 전송과 링크만 쓴다.

### 1.3 메시지
| 종류 | 색 | 예 |
|---|---|---|
| 성공 (ok) | 초록 바탕 | 단어를 추가했습니다. |
| 실패 (error) | 빨강 바탕 | 이미 등록된 단어입니다: apple |

### 1.4 삭제 확인
- 단어 삭제는 브라우저 확인창을 띄운다 (`confirm`). 삭제하면 기록도 함께 지워진다는 안내를 메시지로 준다.

## 3. 화면별 설계

### 3.1 처음 (`/`)
- 카드 2개: 현재 일차 / 전체 일차, 암기한 단어 / 전체 단어.
- 버튼 3개: 암기 시작(주요), 시험 보기, 통계 보기.
- 로그인하지 않았으면 안내 문장과 [로그인], [회원가입] 버튼만 보인다. 그 밖의 화면은 로그인 화면으로 이동한다.

### 3.2 단어 목록 (`/words`)
- 상단: 제목 "단어 (N개)", 검색창(영단어 또는 뜻), 검색 버튼.
- 접이식 "단어 추가" 폼: 영단어, 뜻, 추가 버튼. 추가 후 같은 화면으로 돌아온다.
- 링크: "CSV로 여러 단어 한꺼번에 등록".
- 표: 영단어, 뜻, 수정 링크, 삭제 버튼. 결과가 없으면 "검색 결과가 없습니다" 또는 "등록된 단어가 없습니다".

### 3.3 단어 수정 (`/words/<id>/edit`)
- 영단어와 뜻 입력칸에 현재 값을 채운다. 저장 후 목록으로 돌아간다. 충돌이면 같은 화면에 메시지.

### 3.4 CSV 가져오기 (`/words/import`)
- 안내: 첫 줄 `영단어,뜻`, UTF-8, 20MB 이하. 중복은 먼저 나온 뜻을 쓴다고 설명.
- 파일 선택 + 등록 버튼.
- 결과 화면: 요약 한 줄 (추가·중복·형식 오류 개수), 중복 단어 목록 (최대 100개), 오류 줄 목록 (최대 100개).

### 3.5 암기 카드 (`/memorize`)
- 제목: "암기 — N일차". 하루 학습량 표시.
- 이전·다음 일차 링크 (범위 안에서만).
- 진행 표시: "i / 전체".
- 카드: 영단어 (큰 글씨). [뜻 보기] 누르면 뜻 표시 후 [외웠어요](주요) / [아직이에요].
- 하단: 하루 학습량 입력 (5~50) + [바꾸기]. 바꾸면 일차 구성이 바뀐다는 안내.
- 단어가 없으면 "등록된 단어가 없습니다" + 단어 화면 링크.
- 일차를 다 보면 "N일차 끝" 화면: 다음 일차, 처음부터 다시, 시험 보기.

### 3.6 시험 설정 (`/exam`)
- 단어가 4개 미만이면 안내만 표시 (시험 불가).
- 문제 수 (1~50, 기본 10), 방향 라디오 (영→한 기본, 한→영, 섞기), 형식 체크박스 (기본 전부 선택, 하나 이상 필요).
- [시험 시작] 버튼. 형식을 하나도 고르지 않으면 같은 화면에 메시지.
- 힌트: "한 번도 안 본 단어와 자주 틀린 단어가 더 많이 나옵니다."

### 3.7 문항 (`/exam/<id>`)
- 제목: "문제 N / 전체", 방향과 형식 표시.
- 단답형: 영단어(또는 뜻) 제시, 답 입력칸 (자동 포커스), [답하기].
- 4지선다: 제시어, 보기 4개를 2열 버튼으로. 누르면 바로 답.
- OX: 영단어와 제시한 뜻, [O (맞아요)] / [X (틀려요)].

### 3.8 시험 결과 (`/exam/<id>/result`)
- 큰 글씨: 정답 수 / 전체 (정답률%).
- 틀린 문항 표: 문제, 내 답 (빈칸이면 "(빈칸)"), 정답. 모두 맞으면 "모두 맞혔습니다."
- 버튼: 다시 시험 보기, 통계 보기.

### 3.9 통계 (`/stats`)
- 카드 2개: 현재 일차, 암기한 단어.
- 날짜별 정답률 표 (날짜, 문항, 정답, 정답률). 기록이 없으면 안내 문장.
- 회차별 점수 표 (회차, 끝낸 시각, 점수, 정답률). 없으면 안내 문장.
- 자주 틀리는 단어 상위 10개 (영단어, 뜻, 틀린 횟수). 없으면 안내 문장.

## 4. 스타일 규칙
- 배경 흰색, 주요 색 파랑 (`#1976d2`), 정답 초록, 오류 빨강.
- 카드 테두리 옅은 회색, 둥근 모서리. 주요 버튼은 파란 바탕 흰 글씨.
- 본문 글자 16px, 제목 26px (`h1`), 소제목 19px (`h2`).

---

## 5. 도전 기능 화면 (v2.1 구현)
- 로그인과 회원가입 (`/login`, `/signup`): 아이디와 비밀번호 입력. 틀리면 어느 쪽이 틀렸는지 알리지 않는다.
- 상단 메뉴: 로그인하면 아이디와 로그아웃 버튼, 아니면 로그인·회원가입 링크.
- 설정 화면: 암기 값, 시험 기본값, 통계 공개 체크박스.
- 공개 통계 목록과 다른 계정 통계 화면은 읽기 전용이다. 요구사항 명세서 v2.1 4장 참고.
