**버전**: v1.7
**설명**: PyQt6 기반 사용자 인터페이스 설계 (요구사항 명세서 v1.7, 데이터 설계서 v1.5 반영, v1.7: 중복 예문 안내 대화상자 추가, 요구사항과 정합)

## 1. 개요

### 1.1 UI 철학
- **직관성**: 비개발자도 쉽게 사용
- **일관성**: 모든 화면에서 동일한 카드·버튼 패턴
- **응답성**: 버튼 클릭 즉시 반응
- **최소화**: 화면마다 필요한 요소만 둔다
- **투명성**: 진도에 반영되는 것과 아닌 것을 화면에서 구분해 알려준다 (재풀이·보너스 안내)
- **밝고 단순한 학습 화면**: 밝은 배경, 큰 글씨, 한 화면에 한 가지 목표. vocabulary.com의 밝고 단순한 학습 화면 구성을 참고했으며 화면을 그대로 복제하지 않는다.

### 1.2 화면 구성

스마트보카는 **왼쪽 사이드바 메뉴**로 4개 화면을 제공합니다.

1. 홈 (Home) - 대시보드
2. 퀴즈 (Quiz) - 퀴즈 풀이
3. 단어 (Word) - 단어 관리
4. 설정 (Settings) - 학습 설정

### 1.3 공통 UX 원칙
- 화면마다 주요 동작 버튼은 **하나만** 파란색으로 강조한다.
- 데이터가 없는 화면은 빈 상태 안내 문구와 다음 할 일 버튼을 함께 보여준다.
- 확인이 필요한 파괴적 동작(삭제, 초기화, 그만하기)은 빨간 버튼으로 구분하고 확인 대화상자를 거친다.
- 정답·오답 같은 결과 색은 초록·빨강으로만 쓰고, 장식에는 쓰지 않는다.

## 2. 화면 설계

### 2.1 메인 윈도우 (MainWindow)

**기본 정보**:
- 윈도우 크기: 1000 x 700 (고정)
- 제목: "스마트보카"
- 배경: 흰색 (#FFFFFF)

**레이아웃**:
```
┌──────────────────────────────────────────────────────┐
│ 스마트보카                                 [_][□][✕] │
├───────────────┬──────────────────────────────────────┤
│ 스마트보카    │                                      │
│               │                                      │
│ ▣ 홈          │        선택한 메뉴의 콘텐츠          │
│ ▢ 퀴즈        │        (Home / Quiz / Word / Set.)   │
│ ▢ 단어        │                                      │
│ ▢ 설정        │                                      │
│               │        (오른쪽 전체)                 │
│  (약 180px)   │                                      │
└───────────────┴──────────────────────────────────────┘
```

**주요 요소**:
- 왼쪽 사이드바 (폭 약 180px): 앱 이름과 메뉴 4개 (홈, 퀴즈, 단어, 설정)
- 선택된 메뉴: 파란 배경(#1976D2) + 흰 글씨로 강조
- 오른쪽 콘텐츠 영역: 선택한 메뉴의 화면이 전체 폭을 쓴다

**앱 종료 시 동작**: 자동 백업 실행 (요구사항 FR-1.8). 퀴즈 세션이 진행 중이면 세션 정보를 저장한 뒤 종료한다 (FR-3.6).

### 2.2 홈 화면 (Home Tab)

**목적**: 학습 현황을 카드로 한눈에 보여주고, 다음 할 일을 하나의 버튼으로 안내

**레이아웃**:
```
┌──────────────────────────────────────────────────────┐
│ 안녕하세요! 오늘도 한 단어씩 가볼까요?               │
├──────────────────────────────────────────────────────┤
│ ┌───────────┐  ┌───────────┐  ┌───────────┐          │
│ │ 전체 진도  │  │ 등록 단어  │  │ 오늘 학습  │          │
│ │   65%     │  │ 1,500개   │  │ 10개      │          │
│ │ ████████░ │  │ 학습 975  │  │           │          │
│ └───────────┘  └───────────┘  └───────────┘          │
│                                                      │
│ ┌──── 분야별 진도 ──────────────────────────────────┐ │
│ │ 일상      ██████░░░░  70%                         │ │
│ │ 비즈니스  █████░░░░░  55%                         │ │
│ │ 미분류    ██░░░░░░░░  20%                         │ │
│ └───────────────────────────────────────────────────┘ │
│ ┌──── 최근 활동 ────────────────────────────────────┐ │
│ │ 어제 완료 12문항   |   오늘 진행 8/10 진행 중     │ │
│ └───────────────────────────────────────────────────┘ │
│                                  [ 퀴즈 시작하기 ]   │
└──────────────────────────────────────────────────────┘
```

**요소 상세**:

| 요소 | 컴포넌트 | 상세 |
|------|---------|------|
| 인사 줄 | QLabel (제목 20pt) | 짧은 한 줄 인사 |
| 요약 카드 3개 | QFrame 카드 | 전체 진도율(숙달 ÷ 전체, 정수 %), 등록 단어 수와 학습 완료 수, 오늘 학습할 단어 수 |
| 분야별 진도 카드 | QFrame + QProgressBar | 일상 / 비즈니스 / 미분류 3행. 펼치기 버튼은 두지 않는다 |
| 최근 활동 카드 | QLabel | 어제 완료 문항 수, 오늘 진행 (완료 / 구성 문항) |
| 주요 버튼 | QPushButton (파란 주요 버튼) | 세션이 없으면 [퀴즈 시작하기], 세션이 있으면 [이어서 풀기]로 바뀐다. 화면에서 이 버튼만 강조한다 |
| 사이드바 메뉴 | 사이드바 | 단어·설정 화면은 사이드바에서 이동한다. 홈 화면에 별도 버튼을 두지 않는다 |

**빈 상태**: 단어가 0개면 요약 카드 자리에 "단어를 추가해 주세요" 안내 카드를 보여 주고, 사이드바의 [단어] 메뉴로 안내한다.

### 2.3 퀴즈 화면 (Quiz Tab)

#### 2.3.1 퀴즈 시작 전 화면

**레이아웃**:
```
┌──────────────────────────────────────────┐
│ 🎯 퀴즈 준비                             │
├──────────────────────────────────────────┤
│                                          │
│ 오늘의 퀴즈 정보                         │
│                                          │
│ 분야: 비즈니스                           │
│ 일일 학습량: 10개                        │
│                                          │
│ 오늘 퀴즈 구성:                          │
│ • 신규·약한 단어: 7개                    │
│ • 복습 대상: 2개                         │
│ • 자주 틀린 단어: 1개                    │
│                                          │
│ ─────────────────────────────────────── │
│                                          │
│ [퀴즈 시작하기]   [나중에]               │
│                                          │
└──────────────────────────────────────────┘
```

**조건별 안내 문구**:
- 오늘 기본 퀴즈를 이미 완료했으면: "오늘 퀴즈는 완료했습니다. 다시 풀기는 진도에 반영되지 않습니다." 를 표시하고 버튼은 [다시 풀기] [나중에]
- 등록 단어가 설정 학습량보다 적으면: "오늘 퀴즈는 N개 중 M개입니다" 표시
- 등록 단어(전체)가 4개 미만이면: "보기를 만들 단어가 부족합니다. 단어를 더 추가해 주세요" 표시하고 [퀴즈 시작하기] 비활성화. 분야 단어가 4개 미만이어도 보기는 전체 단어에서 채우므로 시작할 수 있다 (FR-3.1-E)
- 이어서 풀기 세션이 있으면 이 화면 대신 이어서 풀기 화면(2.3.5)을 먼저 보여준다. 학생이 [이어서 풀기]를 누른 뒤에 퀴즈 진행 화면(2.3.2)으로 간다

#### 2.3.2 퀴즈 진행 중 화면

**레이아웃**:
```
┌──────────────────────────────────────────────────────┐
│ ▬▬▬▬▬▬▬▬▬▬░░░░░░░░░░░░░░░░░░░░  3/10  (얇은 진행 막대) │
│                                                      │
│ ┌──────────────────────────────────────────────────┐ │
│ │  문제 3 · 한→영                                  │ │
│ │                                                  │ │
│ │              사과                                │ │
│ │          (큰 문제 텍스트, 28pt)                  │ │
│ │                                                  │ │
│ │  ┌────────────────┐    ┌────────────────┐        │ │
│ │  │ ① apple        │    │ ② banana       │        │ │
│ │  └────────────────┘    └────────────────┘        │ │
│ │  ┌────────────────┐    ┌────────────────┐        │ │
│ │  │ ③ orange       │    │ ④ grape        │        │ │
│ │  └────────────────┘    └────────────────┘        │ │
│ │                                                  │ │
│ │  ✓ 정답입니다!   (또는 ✗ 오답입니다. 정답: apple) │ │
│ └──────────────────────────────────────────────────┘ │
│                                                      │
│  [그만하기]                           [다음 문제]    │
└──────────────────────────────────────────────────────┘
```

**요소 상세**:
- 진행 막대: 카드 위 상단에 얇게 (높이 약 6px), 오른쪽에 "현재/전체" 표시
- 카드: 흰 배경(#FFFFFF) + 연한 테두리(#E5E7EB), 모서리 둥글게. 화면 가운데 정렬
- 문제 유형: 카드 왼쪽 위 작은 글씨 (보조 글자색)
- 문제 텍스트: 28pt, 가운데 정렬
- 선택지 버튼: 2 x 2 격자, 버튼 높이 약 56px, 글씨 16pt. 마우스 오버 시 파란 테두리
- 채점 후: 내가 고른 것이 정답이면 초록 배경·초록 테두리, 오답이면 빨간 배경·빨간 테두리. 오답일 때 정답 보기는 초록 테두리로 강조. 4개 모두 비활성화
- 결과 메시지: 카드 하단, 정답은 초록 글씨, 오답은 빨간 글씨
- [다음 문제] 버튼: 채점 전 비활성화. 마지막 문항에서는 [완료]로 바뀐다. 이 화면의 주요 버튼이므로 파란색
- [그만하기] 버튼: 보조 빨간 텍스트 버튼. 확인 대화상자(2.6) 후 세션을 삭제하고 홈으로 이동 (FR-3.6). 이미 제출한 답변 기록은 유지된다. 앱을 종료한 경우에는 세션이 남아 다음 실행 때 이어서 풀 수 있다 (2.1절 종료 동작)

**재풀이 표시**: 재풀이 세션이면 카드 위에 주황색 배지 "다시 풀기 중 · 진도에 반영되지 않습니다"를 표시한다.

#### 2.3.3 보너스 문제 화면

보너스 대상이 없으면 이 화면을 건너뛰고 결과 화면으로 간다 (FR-3.4).

**레이아웃**:
```
┌──────────────────────────────────────────┐
│ 🎁 보너스 문제                           │
├──────────────────────────────────────────┤
│                                          │
│ 기본 퀴즈 10개를 모두 풀었습니다!        │
│                                          │
│ 약한 단어 3개를 집중 공략할까요?         │
│                                          │
│ 대상:                                    │
│ • deadline (정답률 40%)                  │
│ • negotiate (정답률 55%)                 │
│ • portfolio (마지막 복습 15일 전)        │
│                                          │
│ ※ 보너스 결과는 진도율에 반영되지 않습니다 │
│                                          │
│ [보너스 도전하기]   [건너뛰기]           │
│                                          │
└──────────────────────────────────────────┘
```

- 대상은 최대 5개까지 표시한다 (FR-3.4).
- 보너스 진행 화면은 2.3.2와 같고, 상단 배지만 "보너스 · 진도에 반영되지 않습니다"로 바꾼다.
- 보너스 안내는 카드 한 장에 담고, [보너스 도전하기]는 파란 주요 버튼, [건너뛰기]는 보조 버튼으로 둔다.

#### 2.3.5 이어서 풀기 화면 (신규, FR-3.6)

**진입**: 홈 화면의 [이어서 풀기] 버튼 또는 퀴즈 메뉴를 열 때 저장된 세션이 있으면 자동 표시.

**레이아웃**:
```
┌──────────────────────────────────────────┐
│ 📝 이어서 풀기                           │
├──────────────────────────────────────────┤
│                                          │
│ 지난번 퀴즈가 6/10 문항에서 멈췄습니다.  │
│ 세션 날짜: 2026-10-28                    │
│                                          │
│ [이어서 풀기]   [그만하기]               │
│                                          │
└──────────────────────────────────────────┘
```

- [이어서 풀기]: 2.3.2 화면으로 이동. 저장된 문항과 보기를 그대로 사용한다.
- [그만하기]: 확인 대화상자(2.6) 후 세션 정보를 삭제한다. 이미 저장된 답변 기록은 지우지 않는다. 2.3.2의 [그만하기]와 같은 동작이다.
- 세션에 있던 단어가 삭제되었으면 해당 문항은 건너뛴다. 건너뛴 사실은 표시하지 않는다.
- 앱을 닫으면 세션은 삭제하지 않고 유지되어, 다음 실행 때 이 화면이 다시 나타난다.
- 이 화면도 카드 한 장으로 구성한다. [이어서 풀기]는 파란 주요 버튼, [그만하기]는 빨간 보조 버튼이다.

### 2.4 단어 관리 화면 (Word Tab)

**레이아웃**:
```
┌──────────────────────────────────────────────────────┐
│ 📖 단어 관리                                         │
├──────────────────────────────────────────────────────┤
│                                                      │
│ [검색] _____________ [분야: 전체▼] [정렬: 단어순▼] [+ 추가] │
│                                                      │
│ 단어     뜻      상태     습득도  마지막복습  정답/시도  │
│ ──────────────────────────────────────────────────── │
│ apple    사과    숙달     95%     2026-10-20  19/20  [✕] │
│ banana   바나나  학습중   70%     2026-10-21  7/10   [✕] │
│ cat      고양이  복습필요 60%     2026-10-19  6/10   [✕] │
│ dog      개      미학습   -       -           0/0    [✕] │
│ ...                                                  │
│ ──────────────────────────────────────────────────── │
│ 페이지: 1/75 [◄] [►]                                 │
│                                                      │
└──────────────────────────────────────────────────────┘
```

**요소 상세**:

| 요소 | 컴포넌트 | 상세 |
|------|---------|------|
| 검색 | QLineEdit (둥근 검색창, 상단 전체 폭) | 단어 또는 뜻 검색 |
| 분야 필터 | QComboBox (작은 칩 형태) | 전체 / 일상 / 비즈니스 / 미분류 |
| 정렬 | QComboBox | 단어순 / 상태순 / 진도순 (FR-1.2) |
| 추가 | QPushButton (파란 주요 버튼) | 새 단어 추가 팝업 (2.4.1) |
| 테이블 | QTableWidget (행 구분선, 상태는 색 배지) | 단어 목록, 20행/페이지 |
| 페이지 | QLabel + QPushButton | 이전/다음 페이지 |

**테이블 열** (요구사항 FR-1.2, FR-4.2 기준):
- 단어 (영어)
- 뜻 (한글)
- 상태 (미학습 / 학습중 / 복습필요 / 숙달, 색상 배지 4.4 참조)
- 습득도 (%), 시도 0이면 `-`
- 마지막복습 (날짜), 없으면 `-`
- 정답/시도 (예: "7/10")
- 삭제 버튼 (✕)

v1.0의 체크박스 열은 요구사항에 일괄 작업이 없어서 제거했습니다.

**정렬 규칙**: 단어순은 영어 사전순, 상태순은 복습필요 → 학습중 → 미학습 → 숙달 순, 진도순은 습득도 높은 순이다. 세 정렬 모두 시도 0인 행(습득도 `-`)은 맨 뒤에 둔다.

**행 동작**:
- 행 클릭 → 단어 상세 보기 (2.4.2)
- ✕ 클릭 → 삭제 확인 대화상자 (2.6)

#### 2.4.1 단어 추가 / 수정 팝업

추가와 수정은 같은 폼을 쓴다. 수정은 기존 값을 채워서 연다.

**레이아웃**:
```
┌──────────────────────────────┐
│ 새 단어 추가 (수정 시: 단어 수정) │
├──────────────────────────────┤
│                              │
│ 영어 (필수):  ________       │
│ 한글 (필수):  ________       │
│ 분야 (선택):  [미분류▼]     │
│ 난이도 (선택): [1▼]         │
│                              │
│ [저장]  [취소]               │
│                              │
└──────────────────────────────┘
```

- 분야 기본값: 미분류, 난이도 기본값: 1
- 저장 시 영어 중복 검사 (앞뒤 공백 제거, 대소문자 무시). 중복이면 경고하고 저장하지 않음 (FR-1.7-A)
- 추가 저장 후 예문은 상세 보기에서 직접 입력한다. 신규 단어에는 기본 예문이 없다 (FR-1.5)
- 수정 저장 시 학습 기록(Progress)은 유지된다
- [취소]: 변경 없이 닫는다

#### 2.4.2 단어 상세 보기

**레이아웃**:
```
┌──────────────────────────────────────┐
│ apple - 단어 상세                    │
├──────────────────────────────────────┤
│                                      │
│ 영어: apple                          │
│ 한글: 사과                           │
│ 분야: 일상                           │
│ 난이도: 1                            │
│                                      │
│ ─────────────────────────────────── │
│ 예문:                                │
│ ─────────────────────────────────── │
│                                      │
│ 1. I eat an apple every day.         │
│    [출처: 기본]                        │
│                                      │
│ 2. New York is called the Big Apple. │
│    [출처: 기본]                        │
│                                      │
│ 3. 사과를 깎고 있습니다.             │
│    [출처: 사용자] [✕]                │
│                                      │
│ 예문이 부족합니다. 직접 추가해 보세요 │ ← 3개 미만일 때만
│ 새 예문: __________  [추가]          │
│                                      │
│ ─────────────────────────────────── │

│ 정답 19 | 오답 1 | 연속 정답 5        │

│ 다음 복습: 2026-10-25                │
│                                      │
│ [수정]  [삭제]  [닫기]               │
│                                      │
└──────────────────────────────────────┘
```

**요소 상세**:
- 예문 출처 표시: 기본 (CSV) / 사용자
- ✕: 사용자 예문만 삭제 가능 (FR-1.6)
- 새 예문 입력: 공백만 입력하면 [추가]가 비활성화된다 (FR-1.6)
- 같은 단어에 같은 문장이 이미 있으면 저장하지 않고 "중복 예문" 대화상자(2.6)를 띄운다 (FR-1.6)
- 통계: 정답/오답 횟수, 연속 정답, 정답률 (시도 0이면 `-`), 다음 복습 날짜 (FR-4.2)
- 기본 예문이 없는 신규 단어는 예문 목록이 비어 있다. 이때 부족 안내와 입력 칸을 보여준다 (FR-1.5)
- [수정]: 2.4.1 팝업을 수정 모드로 연다
- [삭제]: 삭제 확인 대화상자 (2.6)

**요소 상세**:
- 섹션마다 카드(흰 배경, 연한 테두리)로 묶는다: 학습 설정, 정보, 데이터 관리
- 분야 선택: 라디오 버튼 3개 (일상 / 비즈니스 / 선택안함(전체)). 미분류는 설정 대상이 아니다
- 학습량 선택: 라디오 버튼 4개 (5 / 10 / 15 / 커스텀). 커스텀 선택 시에만 입력칸(1~50) 표시
- 저장 버튼: 학습 설정 카드 하단 오른쪽. 파란 주요 버튼. 변경 전까지 비활성화. 단, 첫 실행(DB 자동 초기화 직후)에는 변경이 없어도 활성화되어 있어 기본값으로 바로 저장할 수 있다 (3.1절)
- 정보: 총 단어, 학습 완료 수, DB 파일 이름, 저장 위치 (배포 모드 `%APPDATA%\SmartVoca\`, 개발 모드 `data/`)
- 데이터 관리 버튼: 백업 만들기(보조 버튼), 백업에서 복구(보조 버튼), 초기화(빨간 버튼, 확인 대화상자 필수)
- 설정은 저장 즉시 반영되며, 퀴즈는 다음 "퀴즈 시작"부터 적용된다 (카드 안 안내 문구)

#### 2.5.1 데이터 관리 동작

| 버튼 | 동작 | 대화상자 |
|------|------|---------|
| [백업 만들기] | 백업 폴더(`backups/`)에 `manual_YYYYMMDD_HHMMSS.db` 생성 (저장 위치는 고르지 않음) | 완료 메시지에 저장 경로 표시 |

## 3. 사용자 플로우 (User Flow)

### 3.1 첫 실행 플로우

```
앱 시작
  ↓
DB 확인
  ├─ DB 없음 → 자동 초기화 (init_db.py)
  ├─ DB 있음, 정상 → 계속
  └─ DB 있음, 손상 → 데이터베이스 오류 대화상자 (2.6)
  ↓
메인 윈도우 표시
  ↓
DB를 새로 만든 경우?
  ├─ 예 → 설정 화면 (분야·일일 학습량 선택)
  │        ↓ [저장] → 홈 화면 표시 (진도율 0%)
  └─ 아니오 → 홈 화면 표시
```

첫 실행 때 설정 화면을 먼저 보여 주는 이유: 학습 분야와 일일 학습량이 퀴즈 구성에 바로 쓰이므로, 기본값으로라도 한 번 정하고 시작하게 한다 (기획서 11.2, 요구사항 5.1과 같은 흐름).

### 3.2 일반적인 학습 플로우

```
홈 화면
  ↓
[퀴즈 시작하기] 클릭 (세션이 있으면 [이어서 풀기])
  ↓
퀴즈 준비 화면 (2.3.1)
  ↓
[퀴즈 시작하기] 클릭 → 세션 생성
  ↓
문제 1~N 풀이 (한→영, 영→한 혼합)
  ├─ 정답 → ✓ 표시, 기록 저장, 진도 반영
  └─ 오답 → ✗ 표시 + 정답 강조, 기록 저장, 진도 반영
  ↓
[다음 문제] 반복 (언제든 [그만하기] → 세션 삭제 후 홈)
  ↓
N개 완료
  ↓
보너스 대상 있음?
  ├─ 없음 → 결과 화면
  └─ 있음 → 보너스 화면 (2.3.3)
       ├─ [보너스 도전하기] → 보너스 문제 풀이 (진도 미반영)
       └─ [건너뛰기] → 결과 화면
  ↓
결과 화면 (정답률, 진도 표시)
  ↓
[홈으로] 또는 [다시 풀기] 클릭
  ↓
홈 화면 (진도율 업데이트)
```

### 3.3 퀴즈 재개 플로우 (신규)

```
앱 실행 또는 퀴즈 메뉴 진입
  ↓
저장된 세션 있음?
  ├─ 없음 → 일반 플로우
  └─ 있음 → 이어서 풀기 화면 (2.3.5)
       ├─ [이어서 풀기] → 저장된 위치의 문항부터 진행
       └─ [그만하기] → 확인 → 세션 삭제 → 홈
```

### 3.4 재풀이 플로우 (신규)

```
결과 화면 → [다시 풀기] 클릭
  ↓
준비 화면 → 안내 "진도에 반영되지 않습니다" 확인
  ↓
[퀴즈 시작하기] → 재풀이 세션 (배지 표시)
  ↓
답변은 기록만 저장, 진도(Progress)는 변하지 않음
```

### 3.5 단어 관리 플로우

```
단어 메뉴 클릭
  ↓
단어 목록 표시 (20개/페이지, 정렬·필터 적용)
  ↓
┌─ [검색] 입력 → 결과 필터링
│
├─ [분야] / [정렬] 선택 → 목록 갱신
│
├─ [+ 추가] 클릭 → 추가 팝업 (2.4.1)
│   ├─ 영어/한글/분야/난이도 입력
│   ├─ [저장] → 중복 검사 → 단어 추가
│   └─ [취소] → 닫기
│
├─ 단어 행 클릭 → 상세 보기 (2.4.2)
│   ├─ 예문 표시 (기본 예문 + 사용자 예문)
│   ├─ 사용자 예문 추가 / 삭제
│   ├─ [수정] → 수정 팝업 (2.4.1, 학습 기록 유지)
│   ├─ [삭제] → 삭제 확인 (2.6)
│   └─ [닫기]
│
└─ [✕] 버튼 클릭 → 삭제 확인 (2.6)
    └─ [삭제] → 단어 삭제 (CASCADE)
```

### 3.6 백업 및 복구 플로우 (신규)

```
설정 메뉴 → [백업 만들기]
  ↓
backups/manual_*.db 생성 → 완료 메시지 (경로 표시)

설정 메뉴 → [백업에서 복구]
  ↓
백업 폴더의 파일 목록에서 선택 → 검증
  ├─ 실패 → 복구 실패 대화상자 (2.6)
  └─ 성공 → 복구 확인 (2.6)
       ├─ [취소] → 종료
       └─ [복구] → pre_restore_*.db 생성 → 복원 → 홈 화면 갱신
```

### 5.1 버튼 상태

```
기본 상태: 회색, 텍스트 검은색
마우스 오버: 밝은 회색, 커서 변경
클릭: 더 어두운 색
비활성화: 회색 + 50% 투명도
```

**비활성화 규칙**:
- 퀴즈 [다음 문제]: 채점 전에는 비활성화
- 퀴즈 선택지: 채점 후 4개 모두 비활성화
- 퀴즈 [퀴즈 시작하기]: 등록 단어(전체)가 4개 미만이면 비활성화
- 설정 [저장]: 변경이 없으면 비활성화
- 단어 추가 [저장]: 영어 또는 한글이 비어 있으면 비활성화
- 예문 [추가]: 공백만 입력하면 비활성화
- 홈 [이어서 풀기]: 세션이 없으면 표시하지 않음

### 5.2 입력 필드

```
기본: 흰색 배경, 검은색 테두리
포커스: 파란색 테두리, 2px 두께
오류: 빨간색 테두리 + 아래에 오류 문구 (예: "이미 등록된 단어입니다")
```

### 5.3 진행 바

```
배경: 연한 회색
진행: Primary 색상 (파란색 #1976D2, 초록은 정답 전용이므로 쓰지 않음)
텍스트: 검은색 (중앙)
높이: 6px (2.3.2 퀴즈 진행 막대와 같다)
```

## 6. 접근성 (Accessibility)

- 모든 버튼에 마우스 오버 시 도움말 (Tooltip)
- 탭 키로 요소 간 이동 가능
- 상태·정답 표시는 색과 텍스트를 함께 사용
- 키보드 단축키 (선택사항):
  - Ctrl+Q: 퀴즈 시작
  - Ctrl+W: 단어 관리
  - Ctrl+S: 설정
  - 1~4: 선택지 선택 (선택 즉시 채점)
  - Enter: 다음 문제 (채점 후에만 동작)
