# 스마트보카 요구사항 명세서

**파일 위치**: `docs/분석_261125_요구사항명세서 v2.0.md`
**작성일**: 2026-11-25
**버전**: v2.0
**설명**: 기말과제 요건(VOCA-FR, VOCA-NFR, VOCA-SUB)을 기준으로 한 웹 앱 요구사항 명세서. 요구마다 구현 여부를 표시한다. v1.x(PyQt6 데스크톱)에서 플랫폼을 웹으로 바꾸면서 메이저 버전을 올렸다.

---

## 1. 개요

### 1.1 목적
영단어를 등록하고, 하루 학습량에 따라 일차별로 카드를 외우고, 시험과 통계로 학습 상태를 확인하는 웹 앱을 만든다.

### 1.2 범위
- 필수(기본) 요구: VOCA-FR-001~004, 011~014, 021~026, 031~034, VOCA-NFR-001~005, VOCA-SUB 제출 요건
- 도전(가산) 요구: VOCA-FR-041~043, 051~053, 061~062 (이번 버전에서는 구현하지 않음, 4장 참고)

### 1.3 용어
| 용어 | 뜻 |
|---|---|
| 일차 | 등록 순서대로 하루 학습량만큼 자른 단어 묶음. 1일차, 2일차 … |
| 카드 | 일차 안에서 한 번에 보여 주는 영단어 한 장 |
| 시험 회차 | 시험 한 번 (문제 수만큼 문항을 풀고 결과를 본 단위) |
| 문항 | 시험에서 단어 하나에 대해 묻는 한 문제 |

## 2. 기능 요구사항 (필수)

### 2.1 단어 관리

| ID | 요구 | 세부 규칙 | 구현 | 위치 |
|---|---|---|---|---|
| VOCA-FR-001 | 영단어와 뜻을 직접 입력 | 영단어: 영문자·공백·하이픈·아포스트로피, 64자 이하. 뜻: 200자 이하, 비어 있으면 안 됨 | 구현 | `/words` POST, `app/word_service.py add_word` |
| VOCA-FR-002 | 단어 목록 보기 | 등록 순서와 무관하게 영단어 순으로 전체 표시 | 구현 | `/words`, `search_words` |
| VOCA-FR-003 | 수정, 삭제 | 수정 시 다른 단어와 영단어가 겹치면 거부. 삭제 시 암기·시험 기록도 함께 삭제 | 구현 (삭제 시 기록 함께 삭제: SQLite 외래키 설정 후 동작, 이슈 #8 수정) | `/words/<id>/edit`, `/words/<id>/delete` |
| VOCA-FR-004 | 제공 CSV(2,000개) 일괄 등록 | 중복 정책: 기존 단어 또는 파일 안에서 먼저 나온 같은 영단어(대소문자·공백 무시)는 건너뜀, 먼저 나온 뜻을 씀. 형식 오류 줄은 줄 번호와 함께 보고 | 구현 | `/words/import`, `import_csv` |
| VOCA-FR-004 | 영단어 또는 뜻으로 검색 | 검색어가 영단어나 뜻 어디든 들어 있으면 표시 (대소문자 무시) | 구현 | `/words?q=`, `search_words` |

> 참고: 요구 번호 VOCA-FR-004는 과제 요건에서 일괄 등록과 검색 두 항목에 쓰인다. 원문 요건 문서의 번호 체계와 대조가 필요하면 `ai-agent/uploads/과제원본/02_software_requirements.md`를 본다.

### 2.2 암기

| ID | 요구 | 세부 규칙 | 구현 | 위치 |
|---|---|---|---|---|
| VOCA-FR-011 | 하루 학습량에 따른 일차별 진도 | 하루 학습량(5~50, 기본 20)만큼 등록 순서대로 잘라 일차를 만든다. 마지막 일차는 남은 단어만 | 구현 | `/memorize`, `study_service.day_word_ids` |
| VOCA-FR-012 | 카드를 한 장씩 보고 뜻 확인 | 영단어를 먼저 보여 주고 [뜻 보기]를 누르면 뜻이 나온다 | 구현 | `/memorize?day=&i=&reveal=1` |
| VOCA-FR-013 | 이전 일차 단어와 자주 틀린 단어 섞기 | 일차 기본 단어 + 이전 일차 단어 약 20% (같은 일차는 항상 같은 목록) + 자주 틀린 단어 최대 3개 | 구현 | `study_service.day_word_ids` |
| VOCA-FR-014 | 암기 이력 DB 저장 | 기록마다 사용자, 시각, 단어, 일차, 응답(외웠어요·아직이에요)을 저장 | 구현 | `study_log` 테이블 |

### 2.3 시험

| ID | 요구 | 세부 규칙 | 구현 | 위치 |
|---|---|---|---|---|
| VOCA-FR-021 | 문제 수 지정 | 1~50개. 등록 단어보다 많으면 단어 수만큼만 출제. 단어가 4개 이상이어야 시험 가능 | 구현 | `/exam`, `exam_service.create_session` |
| VOCA-FR-022 | 미시험·오래된·자주 틀린 단어가 더 많이 출제 | 가중치 추첨. 안 본 단어 3.0, 본 단어는 지난 날수(최대 14일)와 틀린 횟수(최대 5회)로 가산. 한 시험에 같은 단어는 한 번 | 구현 | `exam_service.pick_words` |
| VOCA-FR-023 | 출제 방향 | 영→한, 한→영, 섞기(문항마다 무작위) | 구현 | `/exam` 방향 선택 |
| VOCA-FR-024 | 출제 형식 2가지 이상 | 4지선다(mc), 단답형(short), OX(ox). 하나 이상 선택. 4지선다는 뜻이 같은 단어를 보기에서 뺀다 | 구현 (3종) | `exam_service._build_item` |
| VOCA-FR-025 | 점수, 틀린 문항과 정답 표시 | 끝나면 정답 수와 정답률, 틀린 문항의 문제·내 답·정답 표시 | 구현 | `/exam/<id>/result` |
| VOCA-FR-026 | 문항 단위 이력 DB 저장 | 문항마다 단어, 형식, 방향, 정오, 응답 시각을 저장 | 구현 | `exam_item` 테이블 |

**단답형 채점**: 영→한은 뜻 전체와 일치해야 한다(대소문자·공백 무시). 한→영은 영단어와 일치해야 한다. 뜻이 `/`, `,`, `;`로 나뉘어 있으면 나뉜 뜻 중 하나만 맞아도 정답이다.

### 2.4 학습 진척 통계

| ID | 요구 | 세부 규칙 | 구현 | 위치 |
|---|---|---|---|---|
| VOCA-FR-031 | 현재 일차, 암기 단어 수 / 전체 수 | 현재 일차는 카드 기록이 있는 가장 큰 일차(없으면 1). 암기 수는 "외웠어요"를 한 번이라도 누른 단어 수 | 구현 | `/`, `/stats` |
| VOCA-FR-032 | 회차별·날짜별 정답률 추이 | 날짜별 문항 수·정답 수·정답률, 회차별 점수 | 구현 | `/stats` |
| VOCA-FR-033 | 자주 틀리는 단어 상위 N개 | 틀린 횟수가 많은 순 상위 10개 | 구현 | `/stats` |
| VOCA-FR-034 | 통계는 DB 이력으로 계산 | 화면 값을 받지 않고 모든 수치를 DB 집계로 계산 | 구현 | `app/stats_service.py` |

## 3. 비기능 요구사항 (VOCA-NFR)

| ID | 요구 | 구현 | 확인 방법 |
|---|---|---|---|
| VOCA-NFR-001 | PC 크롬에서 동작 | 구현 (서버 렌더링 HTML, 자바스크립트 없음) | 크롬 실제 확인은 아직 안 함 (미확인) |
| VOCA-NFR-002 | 데이터는 DB 저장, 기본 SQLite | 구현 (SQLite, PostgreSQL 미사용) | 테스트, 컨테이너 재시작 후 데이터 유지 확인 |
| VOCA-NFR-003 | 첫 실행 시 테이블 자동 생성 | 구현 (`db.create_all`) | 테스트, 컨테이너 실행 |
| VOCA-NFR-004 | 비밀값은 환경변수 | 구현 (`SECRET_KEY`, `DB_PATH`) | 코드 검토 (`app/config.py`) |
| VOCA-NFR-005 | 서버 배포 요건 준수 | 구현 (Dockerfile R-01~R-16) | 로컬 컨테이너 실행, `docker-check` 통과 |

## 6. 확정 사항

| 항목 | 결정 | 근거 |
|---|---|---|
| 플랫폼 | 웹 앱 (Flask, 서버 렌더링) | 과제 요건 |
| DB | SQLite | 과제 기본 (PostgreSQL 미사용) |
| 로그인 | 이번 버전 미구현 | 필수 범위 우선 |
| 중복 단어 처리 | 먼저 나온 뜻 유지, 나머지 건너뜀 | FR-004 (직접 정함, 문서화) |
| 시험 가중치 | 안 본 단어 우선, 틀린 단어 가산 | FR-022 |
